UIの見た目を揃える — Theme

この回のねらい：ボタンやラベルの見た目を、1か所で管理する。

ボタンを10個置いて、1つずつ色とフォントを設定していくと、あとで変えたくなったとき10か所直すことになります。Theme はその設定をまとめて持つリソースです。

作り方

  • いちばん上の Control ノードを選ぶ
  • インスペクタの Theme で「新規 Theme」を作る
  • 下パネルに現れる「テーマ」タブを開く
  • 「型を追加」で Button や Label を足し、フォント・文字サイズ・色を決める

Theme は子孫すべてに効きます。いちばん上に1つ割り当てておけば、その下のボタンもラベルも全部そのデザインになります。

1つだけ違うものにしたいとき

そのノードのインスペクタにある Theme Overrides で、個別に上書きできます。ただし多用すると Theme の意味が薄れるので、「基本は Theme、例外だけ Overrides」と決めておくのがよいです。

「大きいボタン」のような種類を作りたいときは、Theme の中で Theme Type Variation を使います。Button を元にした派生を作り、ノード側でその名前を指定します。

幼児向けでは特に効きます

B4のような幼児向けUIでは、ボタンを大きく、文字を太く、間隔を広くする必要があります。これを Theme に一度書いておけば、あとから「もう少し大きく」と調整するのが一瞬で済みます。実機で子どもに触らせると必ず調整したくなるので、この仕組みを先に用意しておくと楽です。

9スライス

ボタンの背景に絵を使うとき、そのまま引き伸ばすと角が歪みます。StyleBoxTexture の9スライスを使うと、角はそのまま・辺だけが伸びる形になります。枠や吹き出しを作るときの必須知識です。

やってみる

Control に Theme を作り、Button の文字サイズを大きくする。同じ画面の他のボタンも一緒に変わることを確認する。
