書き出して配る — エクスポート

この回のねらい：作ったものを、他の人が遊べる形にする。

ここまでやって完成です

エディタで動くだけでは、まだ誰にも遊んでもらえません。1本目を作ったら、必ず一度書き出してみてください。ここで初めて分かる問題（フォントが出ない、音が鳴らない、重い）が必ずあります。

最初の一度だけ：テンプレートの用意

メニューの「エディタ」→「エクスポートテンプレートを管理」から、テンプレートをダウンロードします。数百MBあり、Godotのバージョンごとに必要です。これが無いと書き出せません。

書き出す

  • 「プロジェクト」→「エクスポート」
  • 「追加」で書き出したい形式（Windows Desktop、Web、Android など）を選ぶ
  • 下の「プロジェクトをエクスポート」で保存先を決める
形式用途と注意
Windows Desktopいちばん簡単。.exe ができる
Webブラウザで遊べる。ファイル名を index.html にする
AndroidJDKとAndroid SDKの設定が別途必要。最初は後回しでよい

Web書き出しの注意

できたファイルを直接ダブルクリックしても動きません。Webサーバー経由で開く必要があります。エディタの「ブラウザで実行」を使うか、配信サイトにアップロードして確認してください。

また、Godot 4のWeb書き出しは、サーバー側に特定の設定（SharedArrayBuffer を使うためのヘッダ）が必要な場合があります。配信サイトによっては設定項目が用意されているので、動かないときはそこを確認します。

どこで配るか

場所備考
itch.ioGodot製ゲームの定番。Web版もダウンロード版も置ける。無料。手順は下にまとめました
GameJolt同じくインディー向け。海外中心
自分のサイトWeb書き出しを置くだけ。完全に自由
unityroom には投稿できません

国内のブラウザゲーム投稿先として名前が挙がりますが、unityroom は Unity 製ゲーム専用です。Godotで作ったものは投稿できません。国内向けに公開したい場合は、HTML5ゲームを受け付けている投稿サイトを探すか、itch.io に置いて日本語の紹介文を添える形になります。投稿先の受け入れ条件は変わることがあるので、公開前に各サイトの最新の規約を確認してください。

itch.io に公開する手順

Web版を置く場合の流れです。

  • 1. Godotで Web 向けにエクスポート。出力ファイル名を必ず index.html にする
  • 2. 出力された一式（index.html、.js、.wasm、.pck など）をzipにまとめる。このとき index.html がzipを開いてすぐの場所に来るようにする（フォルダを1段挟むと動きません）
  • 3. itch.io で新規プロジェクトを作り、Kind of project を HTML にする
  • 4. zipをアップロードし、「This file will be played in the browser」にチェックを入れる
  • 5. Viewport dimensions にゲームの表示サイズを入れる。320×180 のゲームなら、2倍や3倍の 640×360、960×540 などにすると見やすい
  • 6. 必要なら Fullscreen button をオンにする
  • 7. SharedArrayBuffer support の項目があればオンにする（Godot 4のWeb書き出しで必要になる場合があります）
  • 8. Visibility を Public にして保存
まず Draft のまま試す

公開設定にする前に、Draft の状態で自分のブラウザから動作を確認してください。手元では動いたのに、アップすると真っ暗ということがよくあります。原因はたいてい、zipの構造か index.html の名前です。

スマートフォンからも確認してください。タッチ操作の反応や、画面サイズの収まりは実機でしか分かりません。

ダウンロード版を一緒に置くこともできます。Windows向けに書き出したものをzipにして同じプロジェクトにアップロードし、そちらは「ブラウザで動かす」のチェックを外します。1つのページで、ブラウザ版とダウンロード版の両方を配れます。

更新のたびに手で上げ直すのが面倒になったら、itch.io が配布している butler というコマンドライン用の道具があります。1行でアップロードできるようになります。

書き出す前のチェック

  • デバッグ用の print を消したか
  • アイコンを設定したか（エクスポート設定の中にあります）
  • ウィンドウサイズは適切か
  • フォントや素材のライセンス表記が必要ではないか
  • 終了する手段があるか（Web以外）
やってみる

B1のバスの押しボタンを Windows 向けに書き出し、できた .exe を実行する。エディタの外で動くことを確認する。
