ウィンドウの設定

プロジェクト設定 → 表示 → ウィンドウで、透過（Per Pixel Transparency）を許可し、枠なし（Borderless）にします。あわせてビューポート側の背景も透過にする必要があります。コードからは次のように制御します。

func _ready() -> void:
    var w := get_window()
    w.transparent = true
    DisplayServer.window_set_flag(
        DisplayServer.WINDOW_FLAG_ALWAYS_ON_TOP, true)

func drag(delta_pos: Vector2i) -> void:
    DisplayServer.window_set_position(
        DisplayServer.window_get_position() + delta_pos)
詰まりやすい点

透過の挙動はOSによって差があります。設計の早い段階で実機で確認してください。後から発覚すると作り直しになります。

常駐するので負荷も設計事項です。毎フレーム全部を描き直す必要はありません。作物の状態が変わったときだけ更新する形にします。

オフライン時間の進行を入れない設計（決定済み）は、実装をかなり楽にします。起動中の経過時間だけを見ればよくなるためです。
