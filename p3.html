モグラ叩き — 家族で交代して遊ぶ

新しく覚える：ゲーム全体の流れを状態で持つ／AnimationPlayerで出入りを作る／制限時間とスコア／複数人のデータを配列で持つ。

ここが最初の山です

B1とB2は「ずっと続く遊び」でした。今回はじめて始まって、終わって、結果が出て、もう一度が揃います。この一周を自分の手で作れると、以降の章はすべて「一周の中身が複雑になっただけ」になります。時間をかける価値のある1本です。

作るものを先に決める

家族で順番に遊ぶモグラ叩き。

9つの穴からモグラが1匹ずつ顔を出す。叩くとつぶれて点が入り、叩かれなければ自分で引っ込む。制限時間は30秒。

「つぎは ○○の ばん」と出て、押すとその人の番が始まる。30秒経つと次の人へ交代。全員が終わると、名前と点数が並んだ結果が出る。「もういちど」で最初から。

モグラは1種類。叩いてはいけないものは出ない。誰でもすぐ分かるルールにします。

この章の考え方の芯

3つ

1. 状態が二重になる。B1では「バスが何をしているか」でした。今回はゲーム全体が何をしているか（タイトル・順番待ち・プレイ中・結果）を持ちます。モグラ自身の状態とは別ものです。混ぜないでください。

2. 終わるときは必ず後片付けをする。時間切れになったら、Timerを止めて、出ているモグラを全部消します。ここを忘れると、結果画面の裏でモグラが出続けます。始めるコードより、終わるコードのほうが忘れられます。

3. 人数分のデータは配列で持つ。変数を score1 score2 と並べると、3人目を足すときに全部書き直しになります。最初から配列にしておけば、人数は何人でも同じコードで動きます。

STEP 2

モグラを作る（AnimationPlayer）

第8回の実践です。出てくる動きを1本だけ作り、引っ込むのは逆再生で済ませます。

新規シーンを作り、ルートを Area2D、名前を Mole にして mole.tscn で保存します。

ノード型設定
MoleArea2Dmole.gd をアタッチ
SpriteColorRectSize (44, 52)、Position (-22, -52)、茶色
CollisionShape2D—Shape に RectangleShape2D、Size (44, 52)、Position (0, -26)
AnimationPlayer—下の2本を作る

アニメーションを2本作ります。

名前長さ内容
pop0.25秒Sprite の position.y を 52 → 0（下から出てくる）
hit0.18秒Sprite の scale を (1,1) → (1.3, 0.4)（つぶれる）

pop の Loop はオフにしてください。オンだと出たり入ったりを繰り返します。

RESET を作っておく

アニメーションの編集中に値が変わってしまうので、第8回で触れた RESET アニメーションを作り、Sprite の position と scale の初期値を入れておくと事故が減ります。

ここで確認

F6でモグラ単体を実行し、アニメーションパネルの再生ボタンで pop と hit が意図どおり動く。

STEP 3

出て、待って、引っ込む

モグラの一生を、モグラ自身に持たせます。Main はまだ触りません。

# mole.gd

extends Area2D

signal hit

const STAY_TIME := 1.1       # 出たまま待つ時間（秒）

var busy := false            # 叩かれた／引っ込み始めた

@onready var anim: AnimationPlayer = $AnimationPlayer


func _ready() -> void:
    input_event.connect(_on_input)
    start()


func start() -> void:
    anim.play("pop")
    await anim.animation_finished
    if busy:
        return
    await get_tree().create_timer(STAY_TIME).timeout
    if busy:
        return
    busy = true
    anim.play_backwards("pop")
    await anim.animation_finished
    queue_free()


func _on_input(_vp: Node, event: InputEvent, _idx: int) -> void:
    if busy:
        return
    if event is InputEventMouseButton and event.pressed:
        busy = true
        hit.emit()
        anim.play("hit")
        await anim.animation_finished
        queue_free()
if busy: return が3回出てくる理由

await で待っている間に、叩かれるかもしれないからです。待ち終わって処理を再開したとき、状況が変わっていないかを必ず確かめます。これを忘れると、叩かれたモグラが引っ込む動きも始めて、二重に消えようとしてエラーになります。

await を使うコードでは、この確認がほぼ毎回必要になります。「待ったあとは疑う」と覚えてください。

ここで確認

F6でモグラ単体を実行。出てきて、少し待って、引っ込んで消える。出ている間にクリックすると、つぶれて消える。

STEP 4

ランダムな穴に出す

Main の仕事はここからです。空いている穴を探してから出すのが要点になります。

Main に SpawnTimer（Timer、Wait Time 0.8秒、Autostart オフ）を置き、timeout を接続してください。インスペクタの Mole Scene に mole.tscn を割り当てます。

# main.gd

extends Node2D

@export var mole_scene: PackedScene

var score := 0

@onready var holes: Node2D = $Board/Holes


func _ready() -> void:
    $SpawnTimer.start()


func _on_spawn_timer_timeout() -> void:
    var empty := holes.get_children().filter(
        func(h): return h.get_child_count() == 1)   # 穴の絵だけ＝空き
    if empty.is_empty():
        return
    var m := mole_scene.instantiate()
    m.hit.connect(_on_mole_hit)
    empty.pick_random().add_child(m)


func _on_mole_hit() -> void:
    score += 1
    print(score)
「空き」の数え方に注意

各 Hole には穴の絵の ColorRect が1つ入っています。だから子が1個なら空き、2個ならモグラがいるという数え方になります。穴の絵を入れていない場合は == 0 です。ここは自分の構成に合わせてください。

この判定を入れないと、同じ穴に2匹重なって出ます。

ここで確認

F5で、ランダムな穴からモグラが次々に出る。同じ穴に2匹重ならない。叩くと出力に数字が増えていく。

STEP 5

制限時間とスコア表示

ここでゲーム全体の状態を導入します。

# main.gd に追加

enum Phase { READY, PLAYING, RESULT }

const ROUND_TIME := 30.0

var phase: Phase = Phase.READY
var time_left := 0.0

@onready var score_label: Label = $HUD/TopBar/ScoreLabel
@onready var time_label: Label  = $HUD/TopBar/TimeLabel


func _process(delta: float) -> void:
    if phase != Phase.PLAYING:
        return
    time_left -= delta
    time_label.text = str(int(ceil(time_left)))
    if time_left <= 0.0:
        end_turn()


func start_turn() -> void:
    phase = Phase.PLAYING
    score = 0
    time_left = ROUND_TIME
    update_hud()
    $SpawnTimer.start()


func end_turn() -> void:
    phase = Phase.READY
    $SpawnTimer.stop()
    clear_moles()
    $WhistleSound.play()


func clear_moles() -> void:
    for h in holes.get_children():
        for c in h.get_children():
            if c is Area2D:          # モグラだけ消す。穴の絵は残す
                c.queue_free()


func update_hud() -> void:
    score_label.text = "てん %d" % score
    time_label.text = str(int(ceil(time_left)))

_ready の $SpawnTimer.start() は消し、代わりに start_turn() を呼ぶようにします。_on_mole_hit も update_hud() を呼ぶ形に直してください。

後片付けを1つの関数にまとめる

clear_moles() のように片付けを名前の付いた関数にしておくと、あとで「もう一度」を作るときにそのまま使えます。終了処理を end_turn() の中に直接書いてしまうと、リトライのときに書き写すことになります。

ここで確認

30秒のカウントダウンが進み、0で笛が鳴ってモグラが全部消える。点数が画面に出ている。時間切れ後にモグラが出てこない。

STEP 7

結果を出して、もう一度

結果画面は、名前と点数を並べるだけです。ラベルをコードで作って並べます。

# main.gd に追加

@onready var result_panel: Control   = $HUD/ResultPanel
@onready var result_list: VBoxContainer = $HUD/ResultPanel/ResultList


func show_result() -> void:
    phase = Phase.RESULT

    for c in result_list.get_children():
        c.queue_free()              # 前回の結果を消す

    var best := 0
    for s in scores:
        best = max(best, s)

    for i in player_names.size():
        var row := Label.new()
        var mark := "　★" if scores[i] == best else ""
        row.text = "%s   %d てん%s" % [player_names[i], scores[i], mark]
        result_list.add_child(row)

    result_panel.show()


func _on_retry_button_pressed() -> void:
    result_panel.hide()
    new_game()
前回の結果を消す1行

result_list の子を消してから作り直しています。これを忘れると、2回目の結果が前回の下に積み重なっていきます。「作る前に消す」は、動的にUIを作るときの定型です。

仕上げ

  • 同点の扱い。上のコードでは、最高点が同じ人全員に★が付きます。1人だけにしたいなら別の書き方が要ります。家族で遊ぶなら、全員に付くほうが平和です。
  • 幼い子には難易度を下げる。STAY_TIME を長くすると、出ている時間が延びて叩きやすくなります。人ごとに変えたいなら、名前と一緒に設定を持たせる形にします。
  • 叩いた手応え。HitSound を鳴らし、点数のラベルを一瞬だけ大きくすると、当たった実感が出ます。
  • 「はじめる」までの間を作る。押した瞬間に始まると身構えられません。「3・2・1」の数秒を入れると、交代のテンポが良くなります。
完成の目安

全員が順番に遊べて、結果が出て、「もういちど」で最初から遊べる。2周目の結果が正しく出る。時間切れの後にモグラが残らない。ここまでできたら、あなたはゲームを1本完成させたことになります。
