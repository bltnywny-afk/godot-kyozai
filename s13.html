シグナル — 下から上へ知らせる

この回のねらい：ノード同士の依存を一方通行に保つ。

シグナルは「何かが起きた」という通知です。押されたボタン、体力が0になった敵、範囲に入った物体。それぞれが声を上げ、聞きたい人が勝手に聞きます。

使う側

ノードドック（右側の「ノード」タブ）にシグナル一覧があり、ダブルクリックで接続先を選べます。コードでも書けます。

func _ready() -> void:
    $Button.pressed.connect(_on_button_pressed)

func _on_button_pressed() -> void:
    print("押された")

自分で作る側

# enemy.gd
signal died(points: int)

func take_damage(n: int) -> void:
    hp -= n
    if hp <= 0:
        died.emit(10)
        queue_free()

方向のルール

これだけは守る

上（親）から下（子）へは、メソッドを直接呼ぶ。下から上へは、シグナルで知らせる。

敵が「スコアを10増やせ」とHUDを直接触りに行くと、敵はHUDが存在するレベルでしか使えなくなります。敵は died と叫ぶだけにして、誰が聞くかは上に任せる。こうすると敵シーンは単体でテストでき、別のステージにもそのまま置けます。

やってみる

Buttonを置き、ノードドックの pressed をダブルクリックして接続する。生成された関数に print を書いて実行する。
