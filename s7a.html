マップを描く — TileSetとTileMapLayer

この回のねらい：Godot内蔵のマップエディタで、地形を描けるようにする。

Godotにはマップエディタが内蔵されています。別のツールを用意する必要はありません。2Dビューの上で、ペンで直接タイルを置いていきます。

登場人物は3つ

もの正体役割
タイル画像PNG1枚16×16などのマス目に並べた素材
TileSetリソースどのマスが1枚のタイルか、当たり判定はどうか
TileMapLayerノード実際に地形を並べる場所

混乱しやすいのは、TileSet が「タイルの図鑑」で、TileMapLayer が「それを並べた地図」という関係です。図鑑は1つ作れば、複数の地図から使い回せます。

準備の手順

  • TileMapLayer ノードを追加する
  • インスペクタの Tile Set で「新規 TileSet」を作る
  • 作った TileSet をクリックし、Tile Size を 16 × 16 にする
  • 下パネルに現れる「TileSet」タブを開き、左下の「＋」でタイル画像を追加する
  • 「タイルを自動的に作成しますか？」と聞かれたら「はい」

これで図鑑ができました。下パネルを「TileMap」タブに切り替えると、左にタイルの一覧が出ます。

描く

操作やること
置くパレットでタイルを選び、ビュー上をドラッグ
消す右ドラッグ、または消しゴムを選んでドラッグ
まとめて塗る上部の矩形ツール、または塗りつぶしツール
タイルを吸い取るCtrl を押しながらクリック（スポイト）
複数マスをまとめて置くパレット上でドラッグして範囲選択

当たり判定を付ける

タイルを置いただけでは、地形は当たりません。ここが最初の関門です。

  • TileSet を選び、インスペクタで「物理レイヤー」を1つ追加する
  • その Layer を world にする
  • 下パネル「TileSet」タブ →「ペイント」を選び、対象を「物理レイヤー0」にする
  • 各タイルをクリックすると当たり形を描ける。四角いタイルなら、既定の矩形ボタンで一発
すり抜けるときの確認順

1. TileSet に物理レイヤーがあるか　2. タイルごとに当たり形を描いたか　3. 動かすノードの Mask に world が入っているか。この3つで大半は解決します。

地形（オートタイル）を使う

これを知っているかどうかで、マップ作りの時間が数倍変わります。

草地と土の境目を、角のタイル・辺のタイルと1枚ずつ選んで置いていくのは大変な作業です。地形機能を設定すると、隣り合うタイルを見て自動で正しい形を選んでくれます。

  • TileSet のインスペクタで「地形セット」を1つ追加し、モードを 「角と辺」 にする
  • その中に地形を1つ作り、名前を「草」などにする
  • 「ペイント」で対象を「地形」にし、各タイルのどの角・辺が草かを塗っていく
  • 「TileMap」タブに「地形」の項目が増えるので、それを選んで描く

あとは大まかに塗るだけで、境界のタイルが自動的に選ばれます。設定に10分ほどかかりますが、1面描くだけで元が取れます。

レイヤーを分ける

TileMapLayer は複数置けます。ノードを分けて重ねる形です。

Level
├─ Ground     (TileMapLayer)   地面。当たり判定なし
├─ Walls      (TileMapLayer)   壁。当たり判定あり
└─ Decoration (TileMapLayer)   草や看板。当たり判定なし

こうしておくと、地面を描き替えても壁が消えません。当たり判定を持つのは Walls だけにします。

敵やアイテムもパレットから置ける

TileSet のソースには、画像だけでなくシーンコレクションも追加できます。ここに enemy.tscn や coin.tscn を登録すると、タイルを描くのと同じ操作で敵やアイテムを配置できます。1つずつドラッグして並べるより圧倒的に速いです。

タイルに情報を持たせる

TileSet の「カスタムデータレイヤー」を使うと、タイルごとに好きな値を持たせられます。「このタイルは水」「このタイルは足音が違う」といった情報です。

var data := tile_map.get_cell_tile_data(coords)
if data and data.get_custom_data("is_water"):
    slow_down()

B7のローグライクで高さや水量を扱うときにも、この考え方が下敷きになります。

外部ツールを使うべきか

Tiled や LDtk という専用のマップエディタもあり、読み込むプラグインも存在します。ただ、Godot 4の内蔵エディタは十分に強力で、プラグインを入れるとバージョン更新のたびに追従する手間が発生します。特別な理由がない限り、内蔵のもので進めてください。

現実的な話

マップ作りはプログラミングではなく作業です。そして制作時間の大半をここに持っていかれます。だから1面を小さくしてください。「短い面をたくさん」のほうが、「長い面を少し」より必ず早く完成します。

やってみる

TileMapLayer を1つ置き、16×16のタイル画像を登録して、地面を10マスほど描く。物理レイヤーを設定して、その上をキャラクターが歩けることを確認する。
