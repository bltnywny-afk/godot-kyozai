◂ もくじ第6部 実践 — 9本を作る／アクションRPG

実践 B6 · 全11ステップ · 規模：6〜8週間

探索とダンジョン — ゼルダ1風アクションRPG

新しく覚える：ステートマシン／向きの管理とY-sort／画面単位のカメラ／会話システム／鍵と扉／セーブとロード。

この章の位置づけ

見下ろし型の探索アクション。剣を振り、村人と話し、鍵を見つけて扉を開け、ダンジョンに潜る。ゼルダ1のように、画面が1つずつ切り替わる作りにします。

ここで覚えるマップ間の移動・会話・所持品・セーブは、そのままB5の和風アクションに町パートを足す材料になります。2本が揃うと、ゴエモンのような「町を歩いて手形を手に入れ、道中へ出る」構造が組めます。

この章がいちばん重い理由

B5までは「新しい仕組みが増える」章でした。この章は仕組み同士が絡み合う章です。会話中は歩けない、攻撃中は向きを変えられない、被弾中は入力を受けない。この交通整理ができないと、どこを触っても他が壊れるようになります。だからSTEP 4のステートマシンが、この章の心臓部です。

作るものを先に決める

ゼルダ1風の探索アクション。

見下ろし視点。8方向に歩き、剣を振って敵を倒す。画面の端まで行くと、次の画面へカメラがスライドする。

村人に話しかけるとヒントをくれる。鍵を拾い、鍵のかかった扉を開けてダンジョンへ。ダンジョンの中も同じ仕組みで進む。

セーブポイントで記録すると、次に起動したとき続きから遊べる。お店や買い物はない。

この章の考え方の芯

3つ

1. 状態は1つの変数で持ち、処理を match で分ける。「攻撃中フラグ」「会話中フラグ」「無敵フラグ」を並べると、攻撃中かつ会話中という有り得ない状態が作れてしまいます。同時に1つしか成立しないものは、enum1つにまとめます。

2. 向きは1か所で持つ。facing という変数ひとつを、アニメーションの選択にも剣の判定の回転にも使います。別々に持つと必ずずれます。

3. 世界に起きた変化は Autoload に記録する。開けた扉、拾った鍵、倒したボス。これらを部屋のシーンが持っていると、部屋を出入りするたびに元に戻ります。永続する事実は GameState に置くと決めてください。

STEP 1

8方向に動き、向きを持つ

ノード型設定
PlayerCharacterBody2DLayer「player」、Mask「world」
SpriteSprite2D16×16。Offset (0, -8)（原点を足元にする）
CollisionShape2D—Size (12, 8)、Position (0, -4)
当たり判定は足元だけ

見下ろし型では、体全体ではなく足元の小さな矩形を当たり判定にします。頭の部分まで含めると、壁の上の方に頭がめり込めなくなり、狭い通路が通れなくなります。ゼルダもマリオRPGも、見下ろしのゲームはほぼ全部この作りです。

# player.gd

extends CharacterBody2D

const SPEED := 70.0

var facing := Vector2.DOWN

@onready var sword_pivot: Node2D = $SwordPivot


func _physics_process(_delta: float) -> void:
    var input := Input.get_vector("move_left", "move_right", "move_up", "move_down")
    velocity = input * SPEED
    update_facing(input)
    move_and_slide()


func update_facing(input: Vector2) -> void:
    if input == Vector2.ZERO:
        return
    # 移動は8方向だが、向きは4方向に丸める
    if abs(input.x) > abs(input.y):
        facing = Vector2.RIGHT if input.x > 0.0 else Vector2.LEFT
    else:
        facing = Vector2.DOWN if input.y > 0.0 else Vector2.UP
    sword_pivot.rotation = facing.angle()

Input.get_vector は4つのアクションから方向ベクトルを作ってくれます。斜めでも長さが1を超えないので、斜め移動だけ速くなる問題が起きません。自分で計算すると必ずこれを踏みます。

ここで確認

8方向に動く。斜めが速くならない。壁で止まる。

STEP 2

Y-sortで前後を出す

見下ろし型では、画面の下にいるものほど手前に描かれるべきです。第17回の内容です。

ノード設定

Offset を使う理由

Sprite2D の Position を動かすと、当たり判定との位置関係も変わってしまいます。絵だけをずらしたいときは Offset を使ってください。ノードの原点は足元に置いたまま、絵だけが上に立ちます。

ここで確認

木や家の下側を歩くと手前に、上側を歩くと後ろに隠れる。

STEP 3

剣を振る

アニメーションは1本だけ作ります。向きの違いは SwordPivot の回転で表現するので、4方向ぶん作る必要はありません。

ノード型設定
SwordPivotNode2DPosition (0, -6)
SwordSpriteSprite2DPosition (10, 0)、既定では非表示
SwordAreaArea2DLayer なし、Mask「enemy」、Monitoring オフ
└ CollisionShape2D—Size (16, 12)、Position (12, 0)
AnimationPlayer—attack（0.28秒）

attack には、SwordSprite の表示・回転の動きに加えて、メソッド呼び出しトラックで sword_on（0.08秒）と sword_off（0.20秒）を入れます。第8回・B5と同じ形です。

# player.gd に追加

@onready var anim: AnimationPlayer = $AnimationPlayer
@onready var sword_area: Area2D = $SwordPivot/SwordArea


func _ready() -> void:
    sword_area.monitoring = false
    sword_area.body_entered.connect(_on_sword_hit)


func sword_on() -> void:
    sword_area.set_deferred("monitoring", true)


func sword_off() -> void:
    sword_area.set_deferred("monitoring", false)


func _on_sword_hit(body: Node) -> void:
    if body.has_method("take_damage"):
        body.take_damage(1, (body.global_position - global_position).normalized())

ダメージを与えるときに向きも一緒に渡しています。敵を吹き飛ばす方向に使います。

STEP 4

ステートマシンを入れる

この章の心臓部です。いままでの if を、状態で整理し直します。

# player.gd を書き換える

enum State { MOVE, ATTACK, HURT, TALK }

var state: State = State.MOVE


func _physics_process(delta: float) -> void:
    match state:
        State.MOVE:
            state_move()
        State.ATTACK:
            velocity = Vector2.ZERO
        State.HURT:
            velocity = velocity.move_toward(Vector2.ZERO, 400.0 * delta)
        State.TALK:
            velocity = Vector2.ZERO
    move_and_slide()


func state_move() -> void:
    var input := Input.get_vector("move_left", "move_right", "move_up", "move_down")
    velocity = input * SPEED
    update_facing(input)

    if Input.is_action_just_pressed("attack"):
        do_attack()


func do_attack() -> void:
    state = State.ATTACK
    anim.play("attack")
    await anim.animation_finished
    if state == State.ATTACK:      # 途中で被弾していたら戻さない
        state = State.MOVE
状態を「戻す」ときの注意

攻撃アニメが終わったとき、無条件に state = State.MOVE と書きたくなります。ですが攻撃中に敵に触れて HURT になっているかもしれません。そこで MOVE に戻すと、のけぞりが消えます。

if state == State.ATTACK の一行が、それを防いでいます。B3の if busy: return と同じ考え方です。await のあとは、状況が変わっていないかを確かめる。

状態が増えたときは、この match に一行足すだけで済みます。if の重ね書きと違い、増えても読めなくなりません。

ここで確認

攻撃中は歩けず、向きも変わらない。攻撃が終わると動ける。

STEP 5

画面単位でカメラを動かす

ゼルダ1の「部屋が切り替わる」感じを作ります。マップは1つの大きな TileMapLayerで、カメラだけが画面単位で動きます。マップの描き方は第7回のとおりです。

Camera2D は Player の子ではなく、World の直下に置いてください。

# room_camera.gd

extends Camera2D

const ROOM := Vector2(256.0, 176.0)

var room := Vector2i(-999, -999)
var sliding := false

@onready var player: Node2D = get_parent().get_node("Entities/Player")


func _ready() -> void:
    snap_now()


func _process(_delta: float) -> void:
    if sliding:
        return
    var here := current_room()
    if here != room:
        slide_to(here)


func current_room() -> Vector2i:
    return Vector2i(
        floori(player.global_position.x / ROOM.x),
        floori(player.global_position.y / ROOM.y)
    )


func room_center(r: Vector2i) -> Vector2:
    return Vector2(r) * ROOM + ROOM * 0.5


func snap_now() -> void:
    room = current_room()
    global_position = room_center(room)


func slide_to(r: Vector2i) -> void:
    room = r
    sliding = true
    var t := create_tween()
    t.tween_property(self, "global_position", room_center(r), 0.35)
    await t.finished
    sliding = false
部屋の番号は割り算で出る

プレイヤーの座標を1部屋の大きさで割って切り捨てると、いま何番目の部屋にいるかが出ます。マップに部屋の区切りを置く必要はありません。タイルを描くだけで、部屋の区切りは自動的に決まります。

sliding のフラグは、スライド中に次の判定が走るのを止めています。これが無いと、境界上で行ったり来たりしたときにカメラが暴れます。

ここで確認

画面の端を越えると、カメラが隣の画面へすーっとスライドする。戻ると元の画面へ戻る。

STEP 6

敵と体力

B5の敵と違い、重力がありません。プレイヤーを追いかける形にします。

# enemy.gd

extends CharacterBody2D

const SPEED := 34.0
const KNOCKBACK := 180.0

var hp := 2
var knockback := Vector2.ZERO

@onready var player: Node2D = get_tree().get_first_node_in_group("player")


func _ready() -> void:
    $TouchBox.body_entered.connect(_on_touch)


func _physics_process(delta: float) -> void:
    if knockback.length() > 4.0:
        velocity = knockback
        knockback = knockback.move_toward(Vector2.ZERO, 600.0 * delta)
    elif player:
        velocity = (player.global_position - global_position).normalized() * SPEED
    move_and_slide()


func take_damage(amount: int, dir: Vector2) -> void:
    hp -= amount
    knockback = dir * KNOCKBACK
    modulate = Color(1, 0.4, 0.4)
    await get_tree().create_timer(0.12).timeout
    modulate = Color.WHITE
    if hp <= 0:
        queue_free()


func _on_touch(body: Node) -> void:
    if body.has_method("take_damage"):
        body.take_damage(1, (body.global_position - global_position).normalized())

Player をグループ player に入れておいてください。get_first_node_in_group でどこからでも取れるようになります。ノードパスで辿るより、階層を変えても壊れません（第14回）。

# player.gd に追加

signal health_changed(value: int)

const INVINCIBLE_TIME := 0.9

var invincible := false


func take_damage(amount: int, dir: Vector2) -> void:
    if invincible or state == State.TALK:
        return
    GameState.hp -= amount
    health_changed.emit(GameState.hp)

    state = State.HURT
    velocity = dir * 200.0
    invincible = true

    var t := create_tween().set_loops(5)
    t.tween_property($Sprite, "modulate:a", 0.2, 0.09)
    t.tween_property($Sprite, "modulate:a", 1.0, 0.09)

    await get_tree().create_timer(0.35).timeout
    if state == State.HURT:
        state = State.MOVE
    await get_tree().create_timer(INVINCIBLE_TIME - 0.35).timeout
    $Sprite.modulate.a = 1.0
    invincible = false
ここで確認

敵が追ってくる。剣で2回叩くと倒せる。倒すとき吹き飛ぶ。触れると自分がのけぞって点滅する。

STEP 7

村人と会話する

会話ウィンドウはどのマップでも使うので、Autoload にします（第15回）。

dialog.tscn を新規作成。ルートを CanvasLayer、子に Panel と Label を置き、プロジェクト設定 → Autoload に Dialog として登録します。

# dialog.gd

extends CanvasLayer

signal finished

var lines: Array[String] = []
var index := 0

@onready var label: Label = $Panel/Label


func _ready() -> void:
    hide()


func start(new_lines: Array[String]) -> void:
    lines = new_lines
    index = 0
    label.text = lines[0]
    show()


func _unhandled_input(event: InputEvent) -> void:
    if not visible:
        return
    if event.is_action_pressed("talk"):
        index += 1
        if index >= lines.size():
            hide()
            finished.emit()
        else:
            label.text = lines[index]
        get_viewport().set_input_as_handled()
# npc.gd

extends StaticBody2D

@export var lines: Array[String] = ["ここは はじまりの むら。"]


func talk() -> void:
    Dialog.start(lines)

プレイヤー側は、目の前にいる相手を InteractArea で拾います。

# player.gd に追加

var nearby: Node = null

@onready var interact_area: Area2D = $InteractArea


# _ready に追加
    interact_area.body_entered.connect(func(b): if b.has_method("talk"): nearby = b)
    interact_area.body_exited.connect(func(b): if b == nearby: nearby = null)


# state_move の中に追加
    if Input.is_action_just_pressed("talk") and nearby:
        do_talk()


func do_talk() -> void:
    state = State.TALK
    velocity = Vector2.ZERO
    nearby.talk()
    await Dialog.finished
    state = State.MOVE
set_input_as_handled() が要る理由

会話ウィンドウを進めるキーと、話しかけるキーが同じです。これが無いと、1回押しただけで会話が進み、かつ次の会話が始まります。「この入力はもう使った」と宣言することで、後ろに届かなくなります。

InteractArea は Mask に「interact」を入れ、NPC 側の Layer も「interact」にしてください。壁や敵を拾わなくなります。

ここで確認

村人に近づいて話しかけると文が出る。押すたびに次の文へ進む。会話中は歩けない。終わると動ける。

STEP 8

鍵と扉

ここで初めて「世界に起きた変化」を扱います。開けた扉は、部屋を出入りしても開いたままでなければいけません。

# game_state.gd
# プロジェクト設定 → Autoload に GameState として登録

extends Node

var hp := 3
var max_hp := 3
var keys := 0
var opened_doors := {}        # 扉のID → true
var next_spawn := "start"     # 次のマップでどこに出るか
# door.gd

extends StaticBody2D

@export var door_id: String = ""


func _ready() -> void:
    if GameState.opened_doors.has(door_id):
        queue_free()          # もう開けてある
    $OpenArea.body_entered.connect(_on_body_entered)


func _on_body_entered(body: Node) -> void:
    if not body.is_in_group("player"):
        return
    if GameState.keys <= 0:
        Dialog.start(["かぎが かかっている。"])
        return
    GameState.keys -= 1
    GameState.opened_doors[door_id] = true
    $OpenSound.play()
    await $OpenSound.finished
    queue_free()
door_id を必ず違う値にする

扉を置くたびに、インスペクタで door_id に固有の名前（dungeon1_entrance など）を入れてください。空のままだと、1つ開けた瞬間に全部の扉が開きます。同じIDとして記録されるからです。

この「IDで世界の変化を覚える」やり方は、宝箱・倒したボス・イベントの進行など、あらゆる場面で同じ形で使えます。

鍵は小判（B5）と同じ Area2D です。拾ったら GameState.keys += 1 して消えます。

ここで確認

鍵を持たずに扉に触れると「かぎが かかっている」。鍵を拾ってから触れると開く。別の部屋へ行って戻っても開いたまま。

STEP 9

ダンジョンへの出入り

ダンジョンは別シーンにします（第16回）。どこに出るかを GameState 経由で伝えます。

extends Area2D

# level.gd

extends Node2D

@onready var player: CharacterBody2D = $Entities/Player


func _ready() -> void:
    var marker := $SpawnPoints.get_node_or_null(GameState.next_spawn)

        player.global_position = marker.global_position
    $RoomCamera.snap_now()

出現位置は名前で指定する

座標を直接書くと、マップを描き替えたときに全部ずれます。Marker2D をマップに置いて、その名前で指定します。ダンジョンから戻ってきたときは from_dungeon という名前のマーカーに出る、という具合です。

snap_now() を忘れると、シーンが切り替わった直後にカメラが前の部屋からスライドしてきます。

ここで確認

洞窟の入口に触れるとダンジョンへ移る。出口から戻ると、洞窟の前に立っている。体力と鍵の数が引き継がれている。

STEP 10

セーブして続きから

GameState の中身を、そのままファイルに書き出します。

# game_state.gd に追加

const SAVE_PATH := "user://save.json"

var scene_path := ""          # いまいるマップ


func save_game() -> void:
    var data := {
        "hp": hp,
        "max_hp": max_hp,
        "keys": keys,
        "opened_doors": opened_doors,
        "scene_path": scene_path,
        "next_spawn": next_spawn,
    }
    var f := FileAccess.open(SAVE_PATH, FileAccess.WRITE)
    f.store_string(JSON.stringify(data))


func has_save() -> bool:
    return FileAccess.file_exists(SAVE_PATH)


func load_game() -> void:
    if not has_save():
        return
    var f := FileAccess.open(SAVE_PATH, FileAccess.READ)
    var data: Dictionary = JSON.parse_string(f.get_as_text())
    hp = int(data.get("hp", 3))
    max_hp = int(data.get("max_hp", 3))
    keys = int(data.get("keys", 0))
    opened_doors = data.get("opened_doors", {})
    scene_path = data.get("scene_path", "")
    next_spawn = data.get("next_spawn", "start")
user:// という場所

ゲームの保存先です。実行環境ごとに適切な場所（Windowsなら AppData の中など）に自動で割り振られます。res:// には書き込めません。書き出したものはエディタのファイルシステムには出てこないので、混乱しないでください。

data.get("hp", 3) のように既定値つきで読むのが要点です。あとで項目を増やしたとき、古いセーブデータを読んでもエラーになりません。

セーブポイント（お地蔵さんなど）は NPC と同じ作りで、talk() の中でセーブします。

# save_point.gd

extends StaticBody2D


func talk() -> void:
    GameState.scene_path = get_tree().current_scene.scene_file_path
    GameState.save_game()
    Dialog.start(["きろくした。"])

# player.gd

extends CharacterBody2D

signal health_changed(value: int)

enum State { MOVE, ATTACK, HURT, TALK }

const SPEED := 70.0
const INVINCIBLE_TIME := 0.9

var state: State = State.MOVE
var facing := Vector2.DOWN
var invincible := false
var nearby: Node = null

@onready var anim: AnimationPlayer = $AnimationPlayer
@onready var sword_pivot: Node2D   = $SwordPivot
@onready var sword_area: Area2D    = $SwordPivot/SwordArea
@onready var interact_area: Area2D = $InteractArea


func _ready() -> void:
    add_to_group("player")
    sword_area.monitoring = false
    sword_area.body_entered.connect(_on_sword_hit)
    interact_area.body_entered.connect(func(b): if b.has_method("talk"): nearby = b)
    interact_area.body_exited.connect(func(b): if b == nearby: nearby = null)


func _physics_process(delta: float) -> void:
    match state:
        State.MOVE:
            state_move()
        State.ATTACK:
            velocity = Vector2.ZERO
        State.HURT:
            velocity = velocity.move_toward(Vector2.ZERO, 400.0 * delta)
        State.TALK:
            velocity = Vector2.ZERO
    move_and_slide()


# ---- 移動 ----
func state_move() -> void:
    var input := Input.get_vector("move_left", "move_right", "move_up", "move_down")
    velocity = input * SPEED
    update_facing(input)

    if Input.is_action_just_pressed("attack"):
        do_attack()
    elif Input.is_action_just_pressed("talk") and nearby:
        do_talk()


func update_facing(input: Vector2) -> void:
    if input == Vector2.ZERO:
        return
    if abs(input.x) > abs(input.y):
        facing = Vector2.RIGHT if input.x > 0.0 else Vector2.LEFT
    else:
        facing = Vector2.DOWN if input.y > 0.0 else Vector2.UP
    sword_pivot.rotation = facing.angle()


# ---- 攻撃 ----
func do_attack() -> void:
    state = State.ATTACK
    anim.play("attack")
    await anim.animation_finished
    if state == State.ATTACK:
        state = State.MOVE


func sword_on() -> void:
    sword_area.set_deferred("monitoring", true)


func sword_off() -> void:
    sword_area.set_deferred("monitoring", false)


func _on_sword_hit(body: Node) -> void:
    if body.has_method("take_damage"):
        body.take_damage(1, (body.global_position - global_position).normalized())


# ---- 会話 ----
func do_talk() -> void:
    state = State.TALK
    velocity = Vector2.ZERO
    nearby.talk()
    await Dialog.finished
    if state == State.TALK:
        state = State.MOVE


# ---- ダメージ ----
func take_damage(amount: int, dir: Vector2) -> void:
    if invincible or state == State.TALK:
        return
    GameState.hp -= amount
    health_changed.emit(GameState.hp)

    state = State.HURT
    velocity = dir * 200.0
    invincible = true

    var t := create_tween().set_loops(5)
    t.tween_property($Sprite, "modulate:a", 0.2, 0.09)
    t.tween_property($Sprite, "modulate:a", 1.0, 0.09)

    await get_tree().create_timer(0.35).timeout
    if state == State.HURT:
        state = State.MOVE
    await get_tree().create_timer(INVINCIBLE_TIME - 0.35).timeout
    $Sprite.modulate.a = 1.0
    invincible = false

# game_state.gd

extends Node

const SAVE_PATH := "user://save.json"

var hp := 3
var max_hp := 3
var keys := 0
var opened_doors := {}
var next_spawn := "start"
var scene_path := ""


func reset() -> void:
    hp = 3
    max_hp = 3
    keys = 0
    opened_doors = {}
    next_spawn = "start"
    scene_path = ""


func save_game() -> void:
    var data := {
        "hp": hp,
        "max_hp": max_hp,
        "keys": keys,
        "opened_doors": opened_doors,
        "scene_path": scene_path,
        "next_spawn": next_spawn,
    }
    var f := FileAccess.open(SAVE_PATH, FileAccess.WRITE)
    f.store_string(JSON.stringify(data))


func has_save() -> bool:
    return FileAccess.file_exists(SAVE_PATH)


func load_game() -> void:
    if not has_save():
        return
    var f := FileAccess.open(SAVE_PATH, FileAccess.READ)
    var data: Dictionary = JSON.parse_string(f.get_as_text())
    hp = int(data.get("hp", 3))
    max_hp = int(data.get("max_hp", 3))
    keys = int(data.get("keys", 0))
    opened_doors = data.get("opened_doors", {})
    scene_path = data.get("scene_path", "")
    next_spawn = data.get("next_spawn", "start")
