解像度とピクセルアートの設定

この回のねらい：ドットをぼやけさせない。

ピクセルアートで最初にやる設定が3つあります。プロジェクト設定で行います。

1. 内部解像度を決める

表示 → ウィンドウ の Viewport Width / Height に、ドット単位の実寸を入れます。Game Boy風なら 160×144。ここは拡大後のサイズではなく、絵の実寸を入れるのがコツです。

2. 引き伸ばし方を決める

同じ画面の下のほうにある Stretch で設定します。ここには Mode と Aspect の2つがあります。

Mode ＝ どう拡大するか

  • viewport … 小さく描いてから拡大する。ドット感が保たれる
  • canvas_items … 拡大してから描く。文字がぼやけにくい

ドット絵が主役なら viewport、UIと文字が主役なら canvas_items。迷ったら viewport です。

Aspect ＝ 画面比が違うときどうするか

作るときに決めた縦横比と、遊ぶ人の画面の縦横比は、たいてい一致しません。そのときの振る舞いを決めます。

値どうなるか向いている場面
keep縦横比を保ち、余りは黒帯になるパソコン向け。レイアウトが絶対に崩れない
expand黒帯なしで画面いっぱい。見える範囲が広がる／狭まるスマホ向け。機種ごとに画面の細長さが違うため

まずは keep で構いません。黒帯は出ますが、どんな画面でもレイアウトが崩れないので、作っている間は考えることが減ります。

スマホで遊ばせるなら expand

スマホは機種ごとに画面の細長さがまちまちです。keep だと上下（または左右）に黒帯が出て、ゲームが画面中央の小さい箱に見えます。expand にすると全面に広がります。

ただし、ただ設定を変えるだけでは済みません。広がった側の長さが機種ごとに変わるので、「画面の下端は y=480」といった固定の座標が使えなくなります。かわりに割合で位置を決める必要があります。

Control系のノードならアンカーという機能でこれができます。Node2D の場合はコードで計算します。具体的な作り方は実践B1のSTEP 0.5で扱っています。

3. 補間を切る

レンダリング → テクスチャ の Default Texture Filter を Nearest にします。これが Linear のままだと、拡大時にドットの境界がにじみます。

個別に切りたいとき

プロジェクト全体ではなく1つのノードだけ変えたい場合は、そのノードのインスペクタで CanvasItem → Texture → Filter を Nearest に変えます。

この3つを最初にやっておくと、以降ずっと悩まずに済みます。プロジェクトを新規作成した直後にまとめて設定する習慣にしてください。

やってみる

第7回でぼやけていたスプライトを、Default Texture Filter を Nearest にして直す。
