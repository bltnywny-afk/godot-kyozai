バスの押しボタン

新しく覚える：状態を enum で持つ／世界を動かして止める／Tweenで減速する／awaitで演出を順番に流す。

作るものを先に決める

幼児向けの、音と反応で遊ぶバスごっこ。

画面の上半分に、横から見たバスが走っている。下半分に大きな押しボタンが1つ。

ボタンを押すと「とまります」ランプが点いてチャイムが鳴る。次のバス停に着くとバスが減速して停まり、ドアが開いて乗客が1人降りる。ドアが閉まると発車し、ランプが消えて、また次のバス停へ向かう。これが延々と続く。

失敗はない。押さなければ通過するだけ。何度押しても壊れない。押せば必ず何か反応が返る。

幼児向けなので、勝ち負けやスコアは入れません。そのぶん反応の確実さに全部を注ぎます。押したのに何も起きない瞬間が1つでもあると、幼児は離れます。

この章の考え方の芯

2つだけ

1. バスは動かない。世界が動く。バスは画面中央に固定したまま、背景と停留所を左へ流します。「停まる」は、流す速度を0にすることです。この視点に立つと、停車の実装が驚くほど簡単になります。

2. いま何をしているかを、変数1つで持つ。走行中・停まりかけ・停車中・発車中。これを enum で持ち、処理の入口で必ず確認します。フラグを何個も並べると、必ず矛盾した状態が生まれます。

ランプはバスではなくボタンにある

実物の路線バスは、押しボタンの表示窓そのものが「とまります」と光ります。指のすぐ下で光るほうが、幼児にとっての報酬になります。バス側にもランプを足したくなったら、それは余裕ができてからです。

絵は後回しでいい

ピクセルアートを先に描くと、そこで力尽きます。最初は全部 ColorRect（色の四角）で作ってください。バスは黄色い長方形、乗客は小さい四角で十分です。動きが完成してから Sprite2D に差し替えます。差し替えは、ノードの型を右クリック →「型を変更」で置き換えるだけです。

STEP 0

プロジェクトの設定

新規プロジェクトを作り、最初に3つだけ設定します。ここを飛ばすと、後で絵がぼやけて直すのが面倒になります。

場所項目値
表示 → ウィンドウViewport Width320
表示 → ウィンドウViewport Height480
表示 → ウィンドウStretch → Modeviewport
表示 → ウィンドウStretch → Aspectexpand
レンダリング → テクスチャDefault Texture FilterNearest

320×480 は縦長です。320が横幅、480が高さ。スマホで遊ぶので縦画面にしています。

Aspect を expand にする意味

スマホは機種ごとに画面の細長さが違います。keep だと 320:480 の比率を守るため、上下に黒帯が出ます。expand にすると黒帯なしで画面いっぱいに広がります。

かわりに、横320は固定のまま、縦の高さだけが機種ごとに変わります。

端末実際のビューポート
iPhone 14 相当320 × 692
やや低い端末320 × 623

つまり X座標は今まで通り数値で書いてよい。Y座標だけが信用できない。「画面の下端は y=480」と書くと、機種によってずれます。この対処が次のステップです。

STEP 0.5

画面の高さに合わせる（アンカー）

縦の高さが機種ごとに変わる以上、「y=300のところにパネルを置く」という書き方はできません。かわりに割合で置きます。「上から1/3のところ」と指定しておけば、高さが何pxでも常に1/3です。

この割合指定の仕組みを、Godotではアンカーと呼びます。Control系のノード（Button、Label、ColorRect など）だけが持っている機能です。

アンカーの値意味
0親の左端／上端
0.333親の 33.3% の位置
1親の右端／下端

ボタン領域をつくる

UI (CanvasLayer) の下に ButtonArea という Control を作り、次の8つの数字を入れます。Anchor が割合、Offset がそこからのズレ（px）です。Offsetは全部0にします。

ノードAnchor（左/上/右/下）Offset結果
ButtonArea0 / 0.333 / 1 / 1全部 0画面の下2/3
Bg0 / 0 / 1 / 1全部 0ButtonArea 全体
ButtonUnit0.11 / 0.06 / 0.89 / 0.94全部 0領域の幅78%・高さ88%
Display0.08 / 0.08 / 0.92 / 0.40全部 0ユニット上部の表示窓
Lamp (Label)0 / 0 / 1 / 1全部 0Display 全体
Knob0.5 / 0.7 / 0.5 / 0.7-65 / -65 / 65 / 65130×130 の丸

Knob だけ書き方が違います。アンカーを4つとも同じ値にすると「点」を指定したことになり、そこからOffsetで大きさを決めます。この形にすると、画面が変わってもKnobは常に130×130の正円のままです。丸くするには Knob に StyleBoxFlat を作り、Corner Radius を4つとも 65 にします。

ノードそのほかの設定
Bg色は車内の壁の色（クリームや薄いグレー）
Display色 #3a3a3a（消灯状態）
LampText「とまります」、上下中央・左右中央ぞろえ
KnobPivot Offset を (65, 65) ＝ サイズの半分
これを忘れると押しても反応しません

Display・Lamp・Knob の3つは、インスペクタの Mouse → Filter を Ignore にしてください。

Control系のノードは既定でマウス入力を受け止めてしまいます。ボタンの上に子ノードを乗せると、子が指をせき止めて、親のButtonまで届きません。Ignoreにすると指がすり抜けて、下のButtonUnitに届きます。「見た目だけの部品」には全部これを設定します。

当たり判定はユニット全体

丸いKnobだけを判定にしたくなりますが、そうしません。ButtonUnit（筐体全体）が Buttonで、Knobはただの飾りです。見た目は丸ボタンでも、筐体のどこを触っても反応する——幼児は狙って押せないので、これが正解です。

バス側は Node2D なのでコードで置く

アンカーは Control 専用の機能です。バスの世界（TopView）は Node2D なので使えません。かわりに、1行だけコードで位置を決めます。

# main.gd

extends Node2D

const BUS_RATIO := 1.0 / 3.0    # 上から何割をバスに使うか


func _ready() -> void:
    get_viewport().size_changed.connect(_layout)
    _layout()


func _layout() -> void:
    $TopView.position.y = get_viewport_rect().size.y * BUS_RATIO

size_changed は画面の大きさが変わったときに飛ぶシグナルです。これを繋いでおくと、スマホを回しても、ブラウザの窓を伸ばしても、勝手に追従します。

TopView の原点を「境界線」に置く

ここが今回いちばん大事な工夫です。TopViewの原点（0,0）を、バスとボタンの境界線に置きます。そしてバスの世界を全部マイナスのY座標で作ります。

TopView の中のY座標
├─ y = -2000   空のいちばん上
├─ y = -120    建物の上
├─ y = -106    バスの屋根
├─ y = -46     道路の上（＝バスの下端）
└─ y = 0       ★原点。ここから下がボタン領域

こうすると、画面の高さが変わったときに直す場所が「TopViewのy」1箇所だけになります。中身のバスや道路の座標は一切さわらなくて済みます。

ここで確認

F5を押すと、画面の下2/3に大きなボタンユニットが出る。「とまります」の文字が見える。ウィンドウの縦を伸び縮みさせても、1/3と2/3の比率が保たれる。ボタンを押したとき、まだ何も起きなくてよい。

STEP 1

背景が流れる

まずバスも何もない状態で、背景だけを左へ流します。

ノード型設定
MainNode2Dmain.gd をアタッチ（やり方は第6回）
TopViewNode2DPosition は _layout() が決めるので触らない
SkyColorRectSize (320, 2000)、Position (0, -2000)、水色
RoadColorRectSize (320, 46)、Position (0, -46)、灰色
SceneryNode2DPosition (0, 0)
BgASprite2D または ColorRectSize (320, 74)、Position (0, -120)
BgBBgA と同じPosition (320, -120)

Y座標が全部マイナスなのは、STEP 0.5 で決めた通り原点が境界線にあり、上へ向かってマイナスだからです。空を2000pxも取っているのは、どんなに縦長の端末でも上端まで届かせるためです。こうしておけば空のサイズを計算し直す必要がありません。

BgA と BgB は同じ絵を2枚並べます。1枚が左へ抜けたら、まとめて右へ戻す。これで無限にループします。

# main.gd に追加

const CRUISE_SPEED  := 60.0    # 走行速度（px/秒）
const SCENERY_WIDTH := 320.0   # 背景1枚の幅

var speed := CRUISE_SPEED

@onready var scenery: Node2D = $TopView/Scenery


func _process(delta: float) -> void:
    scenery.position.x -= speed * delta
    if scenery.position.x <= -SCENERY_WIDTH:
        scenery.position.x += SCENERY_WIDTH

scenery.position.x += SCENERY_WIDTH と足し算にしているのは、0に戻すのではなく行き過ぎた分を残すためです。0に戻すと、フレームごとにわずかにガタつきます。

ここで確認

F5を押すと、背景が右から左へ途切れずに流れ続ける。継ぎ目でカクッと飛ばなければ成功です。

STEP 2

バスを置いて、ボタンとつなぐ

バスは画面中央に固定です。コードでは一切動かしません。ボタンは STEP 0.5 で作ってあるので、ここでは配線だけします。

ノード型設定
BusNode2DPosition (160, -46)　← 道路の上
BodyColorRectSize (110, 60)、Position (-55, -60)
DoorColorRectSize (16, 46)、Position (16, -46)
PassengerColorRectSize (12, 20)、色は好きな色

Body と Door の座標は Bus から見た相対位置なので、STEP 0.5 の座標系に移っても変わりません。動いたのは親の Bus だけです。これが「原点を境界線に置く」ことの効きめです。

なぜ Button か

幼児が指で押すので、当たり判定は大きく確実にする必要があります。Control系の Button は矩形が明確で、押した／離したの判定もGodotが面倒を見てくれます。Area2D でも作れますが、この用途では Button が正解です。絵ができたら TextureButton に差し替えます。

ButtonUnit を選び、右の「ノード」タブから pressed シグナルを Main に接続します。関数名は _on_button_unit_pressed になります。

# 追加

func _on_button_unit_pressed() -> void:
    print("押された")
ここで確認

バスが道路の上に立ち、下に大きなボタンユニットがある。押すと下パネルの「出力」に文字が出る。丸ボタンの外側、筐体のふちを触っても反応する。反応しないときは、子ノードの Mouse Filter が Ignore になっているか確認してください。

STEP 3

状態を持たせ、停留所を流す

ここが本章の核です。いま何をしているのかを1つの変数で表します。

# 追加

enum State { RUNNING, STOPPING, STOPPED, DEPARTING }

const STOP_INTERVAL := 900.0   # 次の停留所までの距離
const STOP_DISTANCE := 40.0    # ここまで来たら減速を始める

var state: State = State.RUNNING
var requested := false          # 停車ボタンが押されたか

@onready var bus_stop: Node2D = $TopView/BusStop
@onready var bus: Node2D      = $TopView/Bus


func _ready() -> void:
    reset_bus_stop()


func reset_bus_stop() -> void:
    bus_stop.position.x = bus.position.x + STOP_INTERVAL

そして _process を、世界を流す処理と判断の処理に分けます。

# _process を書き換える

func _process(delta: float) -> void:
    move_world(delta)

    if state == State.RUNNING and requested:
        var d := bus_stop.position.x - bus.position.x
        if d <= STOP_DISTANCE and d > 0.0:
            begin_stopping()


func move_world(delta: float) -> void:
    var d := speed * delta
    scenery.position.x -= d
    bus_stop.position.x -= d

    if scenery.position.x <= -SCENERY_WIDTH:
        scenery.position.x += SCENERY_WIDTH
    if bus_stop.position.x < -60.0:
        reset_bus_stop()


func begin_stopping() -> void:
    state = State.STOPPING
    print("減速開始")

停留所（BusStop）を TopView の下に作り、Sign として ColorRect を1つ入れておいてください。

ノード型設定
BusStopNode2DPosition (0, -46)　← Xはコードが決める
SignColorRectSize (22, 16)、Position (-11, -58)

Yだけは自分で -46（道路の上）にしておきます。コードが書き換えるのは X だけなので、Y は編集した値がそのまま残ります。

なぜ状態とフラグの両方があるのか

state は「バスがいま物理的に何をしているか」、requested は「乗客が降りたいと言っているか」。別のものなので、別に持ちます。ここを1つにまとめようとすると、必ず表現できない状況が出てきます。

ここで確認

ボタンを押す関数で requested = true にしてみて、しばらく待つと「減速開始」が出力される。まだ止まりません。

STEP 4

ランプとチャイム

押した瞬間の反応を作ります。幼児向けでは、ここが一番大事な部分です。

# _on_button_unit_pressed を書き換える

func _on_button_unit_pressed() -> void:
    press_effect()              # 手応えは必ず返す
    if requested:
        return
    if state == State.STOPPING or state == State.STOPPED:
        return                  # いま停まるところなので受け付けない
    requested = true
    set_lamp(true)
    $Chime.play()


func press_effect() -> void:
    var t := create_tween()
    t.tween_property(knob, "scale", Vector2(0.88, 0.88), 0.06)
    t.tween_property(knob, "scale", Vector2.ONE, 0.12)

沈ませるのは Knob（丸ボタン）だけです。実物も、筐体は動かずボタンだけが沈みます。Knobは130×130の固定サイズなので、Pivot Offset を (65, 65) にしておけば中心から縮みます。これを設定しないと左上へ寄って縮みます。

「とまります」を光らせる

表示窓の色と文字の色を、消灯／点灯で入れ替えます。

# 追加

const LAMP_OFF_BG := Color("#3a3a3a")   # 消灯した表示窓
const LAMP_ON_BG  := Color("#e03b2f")   # 点灯した表示窓（赤）
const LAMP_OFF_FG := Color("#6a6a6a")   # 消灯した文字
const LAMP_ON_FG  := Color("#ffffff")   # 点灯した文字（白）

@onready var display: ColorRect = $UI/ButtonArea/ButtonUnit/Display
@onready var lamp: Label        = $UI/ButtonArea/ButtonUnit/Display/Lamp
@onready var knob: Panel        = $UI/ButtonArea/ButtonUnit/Knob


func set_lamp(on: bool) -> void:
    display.color = LAMP_ON_BG if on else LAMP_OFF_BG
    lamp.add_theme_color_override(
        "font_color", LAMP_ON_FG if on else LAMP_OFF_FG)


# _ready に追加
    set_lamp(false)
hide() ではなく色を変える理由

実物の表示窓は、消えているときも「とまります」の文字がうっすら見えています。消すのではなく暗くするほうが本物に近く、幼児にも「ここが光る場所だ」と伝わります。

ラベルの文字色は add_theme_color_override() で変えます。Labelには color プロパティがないので、テーマの色を個別に上書きする形になります。

press_effect() を return より前に置いているのが要点です。受け付けられない状況でも、押した手応えだけは必ず返ります。

ここで確認

ボタンを押すと、丸ボタンが少し沈んで戻り、チャイムが鳴り、「とまります」の表示窓が赤く光る。連打しても沈む動きは毎回出るが、チャイムは1回だけ。

STEP 5

減速して、停留所にぴたりと停める

速度を0にするだけでは、停留所の手前や先で止まってしまいます。残りの距離を、ちょうど使い切る時間を計算します。

# begin_stopping を書き換える

func begin_stopping() -> void:
    state = State.STOPPING
    var d := bus_stop.position.x - bus.position.x
    var time := 2.0 * d / speed       # 等減速で距離 d を進むのにかかる時間
    var t := create_tween()
    t.tween_property(self, "speed", 0.0, time)
    t.tween_callback(arrive)


func arrive() -> void:
    state = State.STOPPED
    print("到着")

速度が一定の割合で speed から0まで落ちるとき、平均速度は speed / 2。だから進む距離は speed / 2 × time です。これが d と等しくなる time を求めると 2 × d / speed。中学校の等加速度運動そのままです。

ここで曲線を付けない

set_trans(Tween.TRANS_SINE) のような緩急を足したくなりますが、付けると上の計算が合わなくなり、停留所とずれます。Tweenの既定は直線変化なので、何も指定しないのが正解です。緩急が欲しくなったら、そのときに数式を作り直します。

ここで確認

ボタンを押すと、バス停の標識が近づいてきて、なめらかに減速し、バスの真横でぴたりと止まる。出力に「到着」が出る。ずれるなら STOP_DISTANCE ではなく、標識の絵の原点位置を疑ってください。

STEP 6

ドアが開いて、降りて、発車する

順番に起きる演出は await で書くと、上から読める形になります。

# arrive を書き換え、以下を追加

func arrive() -> void:
    state = State.STOPPED
    $DoorSound.play()
    await open_door()
    await let_passenger_out()
    await close_door()
    depart()


func open_door():
    var t := create_tween()
    t.tween_property(door, "scale:x", 0.08, 0.35)
    await t.finished


func close_door():
    var t := create_tween()
    t.tween_property(door, "scale:x", 1.0, 0.35)
    await t.finished


func let_passenger_out():
    passenger.position = Vector2(DOOR_X, GROUND_Y - PASSENGER_H)
    passenger.show()
    var t := create_tween()
    t.tween_property(passenger, "position:x", DOOR_X + 46.0, 1.1)
    await t.finished
    passenger.hide()


func depart() -> void:
    state = State.DEPARTING
    requested = false
    set_lamp(false)
    var t := create_tween()
    t.tween_property(self, "speed", CRUISE_SPEED, 1.5)
    t.tween_callback(_on_departed)


func _on_departed() -> void:
    state = State.RUNNING
# 定数と変数を追加

const DOOR_X      := 176.0   # ドアの位置。絵に合わせて調整する
const GROUND_Y    := -46.0   # 道路の上端（TopView 内のローカル座標）
const PASSENGER_H := 20.0    # 乗客の背丈

@onready var door: ColorRect       = $TopView/Bus/Door
@onready var passenger: ColorRect  = $TopView/Passenger


# _ready に追加
    passenger.hide()

GROUND_Y がマイナスなのは、STEP 0.5 の座標系だからです。ColorRect は左上が原点なので、そのまま置くと道路にめり込みます。背丈のぶん引き算して、足が道路の上に来るようにしています。

ドアの向き

scale:x を縮めると、既定では中心に向かって縮みます。ドアらしく片側へ引き込むには、Door の Centered をオフにして、原点が蝶番の側に来るように配置してください。ColorRect なら最初から左上が原点なので、そのままで自然に見えます。

停留所の標識は、ここでは戻しません。move_world が画面外に出たときに自動で戻します。発車の瞬間に戻すと、標識が目の前で消えてしまいます。

ここで確認

押す → 停まる → ドアが開く → 乗客が降りて歩いて消える → ドアが閉まる → 発車してランプが消える → しばらく走ると次のバス停が来る。ここまで一周したら、ゲームとして完成です。

STEP 7

幼児向けの仕上げ

動くようになってから、遊ぶ相手に合わせて詰めます。

  • 音を先に、絵を後に。押した瞬間に音が出れば、それだけで「効いた」と伝わります。処理はチャイムの再生から書きます。
  • 止められる状態を作らない。ポーズもメニューも要りません。閉じるのは大人の役目です。
  • 速度を落とす。CRUISE_SPEED を下げ、停留所の間隔を詰めて、押してから停まるまでを短くします。幼児は因果関係を数秒しか保持できません。
  • ランプを点滅させる。create_tween().set_loops() で display の modulate:a を往復させると点滅になります。
  • 最後に絵を入れる。ColorRect を右クリック →「型を変更」で Sprite2D にし、Texture を割り当てます。位置とサイズはそのまま引き継がれます。

スマホの実機で確かめる

itch.io に上げて手元のスマホで遊ぶところまでが目標なので、ここで実機を触っておきます。

  • 1回目のチャイムが鳴らないことがある。ブラウザには「ユーザーが触るまで音を出さない」という決まりがあります。タイトル画面を1枚挟んで、そこを1回タップさせてから本編に入るのが確実な対処です。
  • 縦の比率を確かめる。手持ちの機種でバス1/3・ボタン2/3になっているか。ずれていたら BUS_RATIO と ButtonArea のアンカーが揃っているか見ます。
  • itch.io の埋め込みサイズは縦長（400×720 あたり）にし、「Mobile friendly」と「Fullscreen button」を有効にします。
書き出し方は第31回

Web（HTML5）への書き出し手順そのものは第31回にあります。itch.io へのアップロードは、書き出してできたファイル一式をzipにまとめて上げるだけです。

main.gd 全文

extends Node2D

# ---- 状態 ----
enum State { RUNNING, STOPPING, STOPPED, DEPARTING }

# ---- 調整用の値 ----
const BUS_RATIO     := 1.0 / 3.0  # 上から何割をバスに使うか
const CRUISE_SPEED  := 60.0     # 通常の走行速度（px/秒）
const STOP_DISTANCE := 40.0     # 停留所がここまで来たら減速を始める
const STOP_INTERVAL := 900.0    # 次の停留所までの距離
const SCENERY_WIDTH := 320.0    # 背景1枚の幅
const DOOR_X        := 176.0    # ドアの位置
const GROUND_Y      := -46.0    # 道路の上端（TopView 内のローカル座標）
const PASSENGER_H   := 20.0     # 乗客の背丈

# ---- 表示窓の色 ----
const LAMP_OFF_BG := Color("#3a3a3a")
const LAMP_ON_BG  := Color("#e03b2f")
const LAMP_OFF_FG := Color("#6a6a6a")
const LAMP_ON_FG  := Color("#ffffff")

var state: State = State.RUNNING
var requested := false
var speed := CRUISE_SPEED

@onready var scenery: Node2D       = $TopView/Scenery
@onready var bus_stop: Node2D      = $TopView/BusStop
@onready var bus: Node2D           = $TopView/Bus
@onready var door: ColorRect       = $TopView/Bus/Door
@onready var passenger: ColorRect  = $TopView/Passenger
@onready var display: ColorRect    = $UI/ButtonArea/ButtonUnit/Display
@onready var lamp: Label           = $UI/ButtonArea/ButtonUnit/Display/Lamp
@onready var knob: Panel           = $UI/ButtonArea/ButtonUnit/Knob


func _ready() -> void:
    get_viewport().size_changed.connect(_layout)
    _layout()
    set_lamp(false)
    passenger.hide()
    reset_bus_stop()


# ---- 画面の高さに合わせる ----
func _layout() -> void:
    $TopView.position.y = get_viewport_rect().size.y * BUS_RATIO


func _process(delta: float) -> void:
    move_world(delta)

    if state == State.RUNNING and requested:
        var d := bus_stop.position.x - bus.position.x
        if d <= STOP_DISTANCE and d > 0.0:
            begin_stopping()


# ---- 世界を流す。バスは動かない ----
func move_world(delta: float) -> void:
    var d := speed * delta
    scenery.position.x -= d
    bus_stop.position.x -= d

    if scenery.position.x <= -SCENERY_WIDTH:
        scenery.position.x += SCENERY_WIDTH
    if bus_stop.position.x < -60.0:
        reset_bus_stop()


func reset_bus_stop() -> void:
    bus_stop.position.x = bus.position.x + STOP_INTERVAL


# ---- ボタン ----
func _on_button_unit_pressed() -> void:
    press_effect()
    if requested:
        return
    if state == State.STOPPING or state == State.STOPPED:
        return
    requested = true
    set_lamp(true)
    $Chime.play()


func press_effect() -> void:
    var t := create_tween()
    t.tween_property(knob, "scale", Vector2(0.88, 0.88), 0.06)
    t.tween_property(knob, "scale", Vector2.ONE, 0.12)


func set_lamp(on: bool) -> void:
    display.color = LAMP_ON_BG if on else LAMP_OFF_BG
    lamp.add_theme_color_override(
        "font_color", LAMP_ON_FG if on else LAMP_OFF_FG)


# ---- 停車 ----
func begin_stopping() -> void:
    state = State.STOPPING
    var d := bus_stop.position.x - bus.position.x
    var time := 2.0 * d / speed
    var t := create_tween()
    t.tween_property(self, "speed", 0.0, time)
    t.tween_callback(arrive)


func arrive() -> void:
    state = State.STOPPED
    $DoorSound.play()
    await open_door()
    await let_passenger_out()
    await close_door()
    depart()


func open_door():
    var t := create_tween()
    t.tween_property(door, "scale:x", 0.08, 0.35)
    await t.finished


func close_door():
    var t := create_tween()
    t.tween_property(door, "scale:x", 1.0, 0.35)
    await t.finished


func let_passenger_out():
    passenger.position = Vector2(DOOR_X, GROUND_Y - PASSENGER_H)
    passenger.show()
    var t := create_tween()
    t.tween_property(passenger, "position:x", DOOR_X + 46.0, 1.1)
    await t.finished
    passenger.hide()


# ---- 発車 ----
func depart() -> void:
    state = State.DEPARTING
    requested = false
    set_lamp(false)
    var t := create_tween()
    t.tween_property(self, "speed", CRUISE_SPEED, 1.5)
    t.tween_callback(_on_departed)


func _on_departed() -> void:
    state = State.RUNNING
