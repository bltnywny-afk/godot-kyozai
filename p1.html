バスの押しボタン

新しく覚える：状態を enum で持つ／世界を動かして止める／Tweenで減速する／awaitで演出を順番に流す。

作るものを先に決める

幼児向けの、音と反応で遊ぶバスごっこ。

画面の上半分に、横から見たバスが走っている。下半分に大きな押しボタンが1つ。

ボタンを押すと「とまります」ランプが点いてチャイムが鳴る。次のバス停に着くとバスが減速して停まり、ドアが開いて乗客が1人降りる。ドアが閉まると発車し、ランプが消えて、また次のバス停へ向かう。これが延々と続く。

失敗はない。押さなければ通過するだけ。何度押しても壊れない。押せば必ず何か反応が返る。

幼児向けなので、勝ち負けやスコアは入れません。そのぶん反応の確実さに全部を注ぎます。押したのに何も起きない瞬間が1つでもあると、幼児は離れます。

この章の考え方の芯

2つだけ

1. バスは動かない。世界が動く。バスは画面中央に固定したまま、背景と停留所を左へ流します。「停まる」は、流す速度を0にすることです。この視点に立つと、停車の実装が驚くほど簡単になります。

2. いま何をしているかを、変数1つで持つ。走行中・停まりかけ・停車中・発車中。これを enum で持ち、処理の入口で必ず確認します。フラグを何個も並べると、必ず矛盾した状態が生まれます。

ピクセルアートを先に描くと、そこで力尽きます。最初は全部 ColorRect（色の四角）で作ってください。バスは黄色い長方形、乗客は小さい四角で十分です。動きが完成してから Sprite2D に差し替えます。差し替えは、ノードの型を右クリック →「型を変更」で置き換えるだけです。

STEP 1

背景が流れる

まずバスも何もない状態で、背景だけを左へ流します。

ノード型設定
MainNode2Dmain.gd をアタッチ（やり方は第6回）
TopViewNode2DPosition (0, 0)
SkyColorRectSize (320, 300)、水色
SceneryNode2DPosition (0, 0)
BgASprite2D または ColorRect幅320、Position (0, 200)
BgBBgA と同じPosition (320, 200)

BgA と BgB は同じ絵を2枚並べます。1枚が左へ抜けたら、まとめて右へ戻す。これで無限にループします。

extends Node2D

const CRUISE_SPEED  := 60.0    # 走行速度（px/秒）
const SCENERY_WIDTH := 320.0   # 背景1枚の幅

var speed := CRUISE_SPEED

@onready var scenery: Node2D = $TopView/Scenery


func _process(delta: float) -> void:
    scenery.position.x -= speed * delta
    if scenery.position.x <= -SCENERY_WIDTH:
        scenery.position.x += SCENERY_WIDTH

scenery.position.x += SCENERY_WIDTH と足し算にしているのは、0に戻すのではなく行き過ぎた分を残すためです。0に戻すと、フレームごとにわずかにガタつきます。

ここで確認

F5を押すと、背景が右から左へ途切れずに流れ続ける。継ぎ目でカクッと飛ばなければ成功です。

なぜ Button か

幼児が指で押すので、当たり判定は大きく確実にする必要があります。Control系の Button は矩形が明確で、押した／離したの判定もGodotが面倒を見てくれます。Area2D でも作れますが、この用途では Button が正解です。絵ができたら TextureButton に差し替えます。

STEP 3

状態を持たせ、停留所を流す

ここが本章の核です。いま何をしているのかを1つの変数で表します。

# 追加

enum State { RUNNING, STOPPING, STOPPED, DEPARTING }

const STOP_INTERVAL := 900.0   # 次の停留所までの距離
const STOP_DISTANCE := 40.0    # ここまで来たら減速を始める

var state: State = State.RUNNING
var requested := false          # 停車ボタンが押されたか

@onready var bus_stop: Node2D = $TopView/BusStop
@onready var bus: Node2D      = $TopView/Bus


func _ready() -> void:
    reset_bus_stop()


func reset_bus_stop() -> void:
    bus_stop.position.x = bus.position.x + STOP_INTERVAL

そして _process を、世界を流す処理と判断の処理に分けます。

# _process を書き換える

func _process(delta: float) -> void:
    move_world(delta)

    if state == State.RUNNING and requested:
        var d := bus_stop.position.x - bus.position.x
        if d <= STOP_DISTANCE and d > 0.0:
            begin_stopping()


func move_world(delta: float) -> void:
    var d := speed * delta
    scenery.position.x -= d
    bus_stop.position.x -= d

    if scenery.position.x <= -SCENERY_WIDTH:
        scenery.position.x += SCENERY_WIDTH
    if bus_stop.position.x < -60.0:
        reset_bus_stop()


func begin_stopping() -> void:
    state = State.STOPPING
    print("減速開始")

停留所（BusStop）を TopView の下に作り、Sign として ColorRect を1つ入れておいてください。位置はコードが決めるので、エディタ上の位置はどこでも構いません。

なぜ状態とフラグの両方があるのか

state は「バスがいま物理的に何をしているか」、requested は「乗客が降りたいと言っているか」。別のものなので、別に持ちます。ここを1つにまとめようとすると、必ず表現できない状況が出てきます。

ここで確認

ボタンを押す関数で requested = true にしてみて、しばらく待つと「減速開始」が出力される。まだ止まりません。

STEP 4

ランプとチャイム

押した瞬間の反応を作ります。幼児向けでは、ここが一番大事な部分です。

# _on_stop_button_pressed を書き換える

func _on_stop_button_pressed() -> void:
    press_effect()              # 手応えは必ず返す
    if requested:
        return
    if state == State.STOPPING or state == State.STOPPED:
        return                  # いま停まるところなので受け付けない
    requested = true
    lamp.show()
    $Chime.play()


func press_effect() -> void:
    var t := create_tween()
    t.tween_property($UI/StopButton, "scale", Vector2(0.92, 0.92), 0.06)
    t.tween_property($UI/StopButton, "scale", Vector2.ONE, 0.12)
# 変数を追加

@onready var lamp: ColorRect = $TopView/Bus/Lamp


# _ready に追加
    lamp.hide()
設定を1つ

StopButton の Pivot Offset を (100, 60)（サイズの半分）にしてください。Controlノードの拡大は既定で左上を軸にするため、これを設定しないとボタンが左上へ寄って縮みます。

press_effect() を return より前に置いているのが要点です。受け付けられない状況でも、押した手応えだけは必ず返ります。

ここで確認

ボタンを押すと、少し沈んで戻り、チャイムが鳴り、バスの上に赤いランプが点く。連打しても沈む動きは毎回出るが、チャイムは1回だけ。

STEP 5

減速して、停留所にぴたりと停める

速度を0にするだけでは、停留所の手前や先で止まってしまいます。残りの距離を、ちょうど使い切る時間を計算します。

# begin_stopping を書き換える

func begin_stopping() -> void:
    state = State.STOPPING
    var d := bus_stop.position.x - bus.position.x
    var time := 2.0 * d / speed       # 等減速で距離 d を進むのにかかる時間
    var t := create_tween()
    t.tween_property(self, "speed", 0.0, time)
    t.tween_callback(arrive)


func arrive() -> void:
    state = State.STOPPED
    print("到着")

速度が一定の割合で speed から0まで落ちるとき、平均速度は speed / 2。だから進む距離は speed / 2 × time です。これが d と等しくなる time を求めると 2 × d / speed。中学校の等加速度運動そのままです。

ここで曲線を付けない

set_trans(Tween.TRANS_SINE) のような緩急を足したくなりますが、付けると上の計算が合わなくなり、停留所とずれます。Tweenの既定は直線変化なので、何も指定しないのが正解です。緩急が欲しくなったら、そのときに数式を作り直します。

ここで確認

ボタンを押すと、バス停の標識が近づいてきて、なめらかに減速し、バスの真横でぴたりと止まる。出力に「到着」が出る。ずれるなら STOP_DISTANCE ではなく、標識の絵の原点位置を疑ってください。

STEP 6

ドアが開いて、降りて、発車する

順番に起きる演出は await で書くと、上から読める形になります。

# arrive を書き換え、以下を追加

func arrive() -> void:
    state = State.STOPPED
    $DoorSound.play()
    await open_door()
    await let_passenger_out()
    await close_door()
    depart()


func open_door():
    var t := create_tween()
    t.tween_property(door, "scale:x", 0.08, 0.35)
    await t.finished


func close_door():
    var t := create_tween()
    t.tween_property(door, "scale:x", 1.0, 0.35)
    await t.finished


func let_passenger_out():
    passenger.position = Vector2(DOOR_X, GROUND_Y)
    passenger.show()
    var t := create_tween()
    t.tween_property(passenger, "position:x", DOOR_X + 46.0, 1.1)
    await t.finished
    passenger.hide()


func depart() -> void:
    state = State.DEPARTING
    requested = false
    lamp.hide()
    var t := create_tween()
    t.tween_property(self, "speed", CRUISE_SPEED, 1.5)
    t.tween_callback(_on_departed)


func _on_departed() -> void:
    state = State.RUNNING

const GROUND_Y := 250.0   # 地面の高さ

ドアの向き

scale:x を縮めると、既定では中心に向かって縮みます。ドアらしく片側へ引き込むには、Door の Centered をオフにして、原点が蝶番の側に来るように配置してください。ColorRect なら最初から左上が原点なので、そのままで自然に見えます。

停留所の標識は、ここでは戻しません。move_world が画面外に出たときに自動で戻します。発車の瞬間に戻すと、標識が目の前で消えてしまいます。

ここで確認

押す → 停まる → ドアが開く → 乗客が降りて歩いて消える → ドアが閉まる → 発車してランプが消える → しばらく走ると次のバス停が来る。ここまで一周したら、ゲームとして完成です。

STEP 7

幼児向けの仕上げ

動くようになってから、遊ぶ相手に合わせて詰めます。

  • ボタンを大きく。指が太いので、画面幅の6割以上を使って構いません。周囲に他の押せるものを置かない。
  • 音を先に、絵を後に。押した瞬間に音が出れば、それだけで「効いた」と伝わります。処理はチャイムの再生から書きます。
  • 止められる状態を作らない。ポーズもメニューも要りません。閉じるのは大人の役目です。
  • 速度を落とす。CRUISE_SPEED を下げ、停留所の間隔を詰めて、押してから停まるまでを短くします。幼児は因果関係を数秒しか保持できません。
  • ランプを点滅させる。create_tween().set_loops() で modulate:a を往復させると点滅になります。
  • 最後に絵を入れる。ColorRect を右クリック →「型を変更」で Sprite2D にし、Texture を割り当てます。位置とサイズはそのまま引き継がれます。
完成の目安

押す → 停まる → 降りる → 発車、が延々と繰り返せる。何度押しても壊れない。押せば必ず音か動きが返る。この3つが満たせたら、B1は完成です。B2へ進んでください。

ふつう

「つぎは、◯◯」と音声が流れる。停留所の名前と音声ファイルを対にして持たせます。自分の声を録って入れると、幼児の反応が変わります。

むずかしい
