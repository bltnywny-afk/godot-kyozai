グループと、レイヤー／マスク

この回のねらい：「誰が誰にぶつかるか」を設計する。

グループ — 種類でまとめる

ノードドックの「グループ」タブで、ノードに enemy のようなタグを付けられます。

# 全部の敵を消す
get_tree().call_group("enemy", "queue_free")

# ぶつかった相手が敵か調べる
if body.is_in_group("enemy"):
    take_damage(1)

クラス名で判定するよりも壊れにくく、階層にも依存しません。

物理レイヤーとマスク

当たり判定を持つノードには、この2つがあります。混同しやすいので言葉で押さえてください。

  • Layer（レイヤー） = 自分は何者か
  • Mask（マスク） = 自分は何を見るか

プレイヤーの弾が敵にだけ当たってほしいなら、弾の Layer を「弾」、Mask を「敵」だけにします。敵の弾は Mask を「プレイヤー」に。こうすると弾同士は素通りします。

先に名前を付ける

プロジェクト設定 → レイヤー名 → 2D 物理 で、1番を「player」、2番を「enemy」…と名前を付けられます。番号のまま進めると必ず混乱するので、最初に付けてください。

やってみる

レイヤー名に player / enemy / bullet の3つを設定する。既存のノードのLayerとMaskを、名前で選べるようになったことを確認する。
