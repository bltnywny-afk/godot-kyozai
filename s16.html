メインシーンとシーン切り替え

この回のねらい：タイトルからゲームへ、の流れを作る。

起動時に最初に開くシーンはプロジェクト設定 → アプリケーション → 実行 → メインシーンで決めます。最初にF5を押したときに聞かれるのがこれです。

切り替える

get_tree().change_scene_to_file("res://scenes/level_1.tscn")

いま開いているシーンは破棄され、新しいシーンに入れ替わります。前のシーンの状態は残らないので、持ち越したいものは前回のAutoloadに置きます。

読み込みを事前に済ませる

@export var next_scene: PackedScene

func go() -> void:
    get_tree().change_scene_to_packed(next_scene)

ファイルパスの文字列は、ファイルを移動すると壊れます。@export でシーンを指定する形なら、エディタが参照を追従してくれます。

切り替えないという選択

ポーズ画面やインベントリは、シーンを切り替えるのではなく CanvasLayerを上に足して被せるほうが簡単です。get_tree().paused = true と、UI側の Process Mode を Always にする組み合わせで作れます。

やってみる

タイトル用のシーンを作り、ボタンを1つ置いて、押したらレベルへ切り替わるようにする。
