横スクロールアクション — 和風の道中

新しく覚える：CharacterBody2Dと重力・ジャンプ／TileMapLayerでの地形／カメラ追従／攻撃判定／レイヤーとマスク／ステージの繋ぎ。

この章の位置づけ

目指すのは和風の横スクロールアクション。近接攻撃で敵を倒し、小判を集め、関所（ゴール）を目指す。全5ステージ、1面あたり1〜2分。小さくまとまった、最後まで遊べる1本です。

町を歩いて住人と話し、店で買い物をするパートはB6の技術です（マップ間の移動・会話・所持品の管理）。ここでは道中のアクションに絞り、B6でその上に町を足します。2本を作り終えた時点で骨格が揃います。

進め方の注意

これまでの章は新しい要素が2〜3個でした。この章は10個近くあります。1ステップずつ実行して確認しないと、どこが原因か分からなくなります。まとめて書きたくなりますが、必ず区切ってください。

作るものを先に決める

和風の横スクロールアクション。全5ステージ。

主人公は走る・ジャンプする・棒を振って攻撃する。敵に触れると体力が1減り、3つ無くなるとステージの最初からやり直し。穴に落ちても同じ。

道中には小判が置いてある。集めると数が増える。ステージの終わりには関所があり、触れると次のステージへ。

1ステージは1〜2分で終わる短さ。それを5つ並べる。

この章の考え方の芯

3つ

1. 攻撃判定はアニメーションが出す。「攻撃ボタンを押した瞬間に当たり判定を出す」ではなく、棒を振り切った瞬間に出すのが正しい見え方です。第8回のメソッド呼び出しトラックを使うと、秒数をコードで数えずに済みます。

2. 誰が誰にぶつかるかを、先に決める。第19回のレイヤーとマスクを、ここで初めて本格的に使います。プレイヤーの攻撃は敵にだけ当たり、敵の体はプレイヤーにだけ反応する。ここを設定してから作り始めると、後の混乱が消えます。

3. ステージは複製して作る。5面をゼロから5回作るのではありません。1面を完成させ、それを複製して地形を描き替えます。1面目の作りが、そのまま5面分の作りになります。だから1面目は丁寧に作ってください。

STEP 1

床の上で左右に動く

まだ地形も重力も作りません。平らな床の上を左右に動くだけにします。

新規シーンを作り、ルートを CharacterBody2D、名前を Player にして player.tscn で保存します。

ノード型設定
PlayerCharacterBody2DCollision → Layer「player」、Mask「world」
SpriteSprite2D または ColorRect16×24 くらい
CollisionShape2D—RectangleShape2D、Size (12, 24)

テスト用のシーン（あとで level_1.tscn になります）を作り、Player と、床代わりの StaticBody2D（Layer「world」）を置きます。

# player.gd

extends CharacterBody2D

const SPEED := 110.0


func _physics_process(_delta: float) -> void:
    var dir := Input.get_axis("move_left", "move_right")
    velocity.x = dir * SPEED
    move_and_slide()
_process ではなく _physics_process

当たり判定のある動きは _physics_process に書きます。呼ばれる間隔が一定なので、パソコンの速さによって動きが変わりません。物理は physics、演出は process と覚えてください。

ここで確認

左右キーで動く。床をすり抜けない。

STEP 2

重力とジャンプ

# player.gd を書き換える

const SPEED := 110.0
const JUMP  := -290.0


func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity += get_gravity() * delta

    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = JUMP

    var dir := Input.get_axis("move_left", "move_right")
    velocity.x = dir * SPEED
    move_and_slide()

get_gravity() は、プロジェクト設定の重力をそのまま返してくれます。数値を自分で書く必要はありません。

ジャンプの調整

JUMP の値を変えると高さが、プロジェクト設定 → 物理 → 2D → Default Gravity を変えると落ち方が変わります。気持ちよさはこの2つの比率で決まります。重力を強め・ジャンプを高めにすると、キビキビした操作感になります。ゴエモンやカービィの手触りは、ここの調整で作られています。

最初は「高く飛べるが、落ちるのが遅い」になりがちです。重力を上げてみてください。

ここで確認

ジャンプして着地する。空中でジャンプできない。落ちる速さに違和感がない。

STEP 3

TileMapLayerで地形を作る

床の StaticBody2D を消し、TileMapLayer に置き換えます。TileSetの作り方と地形（オートタイル）の設定は第7回にまとめてあります。

  • Level に TileMapLayer を追加
  • インスペクタの Tile Set で「新規 TileSet」を作る
  • 下パネルの「TileSet」タブで、タイル画像をドラッグして追加
  • TileSet の 物理レイヤーを1つ追加し、Layer を「world」にする
  • 各タイルを選び、物理レイヤーのタブで当たり判定の形を描く
ここが一番の落とし穴

タイルを置いただけでは、地形は当たりません。TileSet の物理レイヤーに、タイルごとの当たり形を描く必要があります。四角いタイルなら、当たり判定を作るボタンを押せば矩形が自動で入ります。

すり抜けるときは、まずここを疑ってください。次にプレイヤーの Mask に「world」が入っているかです。

タイルは16×16で作ります。地面・壁・足場の3種類あれば1ステージ作れます。

ここで確認

描いた地形の上を歩ける。段差に登れる。壁で止まる。

STEP 5

棒を振って攻撃する

第8回のメソッド呼び出しトラックが、ここで効きます。

ノード型設定
AttackPivotNode2DPosition (0, -12)
AttackAreaArea2DLayer なし、Mask「enemy」、Monitoring オフ
└ CollisionShape2D—RectangleShape2D (20, 16)、Position (14, 0)
AnimationPlayer—attack を1本（0.3秒）

attack アニメーションには、Sprite の見た目の変化に加えてメソッド呼び出しトラックを2つ入れます。0.1秒の時点で attack_on、0.22秒の時点で attack_off。

# player.gd に追加

var attacking := false

@onready var anim: AnimationPlayer = $AnimationPlayer
@onready var attack_pivot: Node2D = $AttackPivot
@onready var attack_area: Area2D  = $AttackPivot/AttackArea


func _ready() -> void:
    attack_area.monitoring = false
    attack_area.body_entered.connect(_on_attack_hit)


# _physics_process の中、move_and_slide の前に追加
    if Input.is_action_just_pressed("attack") and not attacking:
        do_attack()
    if dir != 0.0:
        attack_pivot.scale.x = 1.0 if dir > 0.0 else -1.0
        $Sprite.flip_h = dir < 0.0


func do_attack() -> void:
    attacking = true
    anim.play("attack")
    await anim.animation_finished
    attacking = false


# アニメーションから呼ばれる
func attack_on() -> void:
    attack_area.set_deferred("monitoring", true)


func attack_off() -> void:
    attack_area.set_deferred("monitoring", false)


func _on_attack_hit(body: Node) -> void:
    if body.has_method("take_damage"):
        body.take_damage(1)
set_deferred を使う理由

当たり判定の有効・無効を、物理計算の最中に直接切り替えるとGodotに怒られます。set_deferred は「安全なタイミングで変えておいて」という指示です。Area2D の monitoring を切り替えるときは、これを付けると覚えてしまってよいです。

has_method("take_damage") で確かめてから呼んでいるのも要点です。こうしておくと、敵でも壺でも「take_damage を持っていれば壊せる」形になり、種類を増やすときにコードを直さずに済みます。

ここで確認

攻撃ボタンで棒を振るアニメーションが再生される。向きを変えると振る向きも変わる。攻撃中に連打しても二重に始まらない。

STEP 6

敵を作る

新規シーン、ルートは CharacterBody2D、enemy.tscn で保存します。

ノード型設定
EnemyCharacterBody2DLayer「enemy」、Mask「world」
Sprite / CollisionShape2D—16×16 くらい
FloorCheckRayCast2DPosition (-10, 0)、Target Position (0, 12)、Enabled オン
TouchBoxArea2DLayer なし、Mask「player」
└ CollisionShape2D—本体と同じくらいの大きさ
# enemy.gd

extends CharacterBody2D

const SPEED := 32.0

var dir := -1.0

@onready var floor_check: RayCast2D = $FloorCheck


func _ready() -> void:
    $TouchBox.body_entered.connect(_on_touch)


func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity += get_gravity() * delta

    # 壁にぶつかった、または足元の先が崖なら引き返す
    if is_on_wall() or not floor_check.is_colliding():
        turn()

    velocity.x = dir * SPEED
    move_and_slide()


func turn() -> void:
    dir = -dir
    floor_check.position.x = -floor_check.position.x
    $Sprite.flip_h = dir > 0.0


func _on_touch(body: Node) -> void:
    if body.has_method("take_damage"):
        body.take_damage(1)


func take_damage(_amount: int) -> void:
    queue_free()
崖を検知する仕組み

FloorCheck は、進行方向の少し先で下に向けて出したセンサーです。そこに床が無ければ、この先は崖ということになります。引き返すときにセンサーの位置も左右反転させるのを忘れないでください。

これが無いと、敵はどんどん穴に落ちていきます。

ここで確認

敵が左右に歩き、壁と崖で引き返す。攻撃すると消える。触れると（まだ何も起きなくてよいが）出力にエラーが出ない。

STEP 7

体力と、やられたときのやり直し

# player.gd に追加

signal died
signal health_changed(value: int)

const MAX_HP := 3
const INVINCIBLE_TIME := 1.2

var hp := MAX_HP
var invincible := false


func take_damage(amount: int) -> void:
    if invincible:
        return
    hp -= amount
    health_changed.emit(hp)
    if hp <= 0:
        died.emit()
        return

    invincible = true
    velocity.y = -160.0          # 少しのけぞる
    var t := create_tween().set_loops(6)
    t.tween_property($Sprite, "modulate:a", 0.2, 0.1)
    t.tween_property($Sprite, "modulate:a", 1.0, 0.1)
    await get_tree().create_timer(INVINCIBLE_TIME).timeout
    $Sprite.modulate.a = 1.0
    invincible = false
無敵時間は必ず入れる

敵に重なっている間、当たり判定は毎フレーム反応します。無敵時間が無いと、触れた瞬間に体力が3つとも消えます。「ダメージを受けたら少しの間は無敵」は、アクションゲームの必須部品です。

点滅させるのは演出のためだけではありません。いま無敵であることをプレイヤーに伝えるための表示です。

Level 側です。KillZone（Area2D、Mask「player」）を画面の下、地形より低い位置に横長に置きます。

# level.gd

extends Node2D

@onready var player: CharacterBody2D = $Entities/Player


func _ready() -> void:
    player.died.connect(restart)
    $KillZone.body_entered.connect(_on_kill_zone)


func _on_kill_zone(body: Node) -> void:
    if body == player:
        restart()


func restart() -> void:
    await get_tree().create_timer(0.6).timeout
    get_tree().reload_current_scene()

reload_current_scene() は、いまのシーンを読み込み直します。これだけでステージが最初の状態に戻ります。敵の位置も小判もすべて元通りです。

ここで確認

敵に触れると体力が減って点滅する。重なり続けても一気に減らない。3回で最初からやり直しになる。穴に落ちても同じ。

STEP 8

小判を集めて、画面に出す

新規シーン、ルートは Area2D、coin.tscn で保存します。

ノード型設定
CoinArea2DLayer なし、Mask「player」。グループ coin に入れる

# coin.gd

extends Area2D

signal collected


func _ready() -> void:
    body_entered.connect(_on_body_entered)


func _on_body_entered(_body: Node) -> void:
    collected.emit()
    set_deferred("monitoring", false)
    var t := create_tween()
    t.tween_property(self, "position:y", position.y - 12.0, 0.25)
    t.parallel().tween_property(self, "modulate:a", 0.0, 0.25)
    await t.finished
    queue_free()

Mask を「player」だけにしてあるので、_body の中身を確かめる必要がありません。プレイヤー以外は最初から反応しないようにレイヤーで決めているからです。これが第19回の設定を先にやっておく効果です。

# level.gd に追加

var coins := 0

@onready var coin_label: Label = $HUD/CoinLabel


# _ready に追加
    for c in get_tree().get_nodes_in_group("coin"):
        c.collected.connect(_on_coin)
    player.health_changed.connect(_on_health_changed)
    update_hud()


func _on_coin() -> void:
    coins += 1
    update_hud()


func _on_health_changed(hp: int) -> void:
    for i in $HUD/Hearts.get_child_count():
        $HUD/Hearts.get_child(i).visible = i < hp


func update_hud() -> void:
    coin_label.text = "小判 %d" % coins
グループで一括接続する

小判を1個ずつエディタで繋ぐのは現実的ではありません。get_nodes_in_group("coin") でまとめて取り、繰り返しで接続します。小判を何個置いてもコードは変わりません。第19回のグループが効く場面です。

ここで確認

小判に触れると消えて、数が増える。ハートが体力に応じて減る。小判を追加で置いても、コードを直さずに動く。

STEP 9

関所を作り、5ステージに増やす

まず、ステージをまたいで小判を持ち越すための Autoload を作ります（第15回）。

# プロジェクト設定 → Autoload に GameState として登録する

extends Node

var coins := 0
var stage := 1


func reset() -> void:
    coins = 0
    stage = 1

Level に Goal（Area2D、Mask「player」）をステージの終端に置きます。

# level.gd に追加

@export var next_scene: PackedScene


# _ready に追加
    coins = GameState.coins
    $Goal.body_entered.connect(_on_goal)
    update_hud()


func _on_goal(body: Node) -> void:
    if body != player:
        return
    GameState.coins = coins
    GameState.stage += 1
    if next_scene:
        get_tree().change_scene_to_packed(next_scene)


# _on_coin を書き換え
func _on_coin() -> void:
    coins += 1
    GameState.coins = coins
    update_hud()
reload_current_scene と小判

やり直しでシーンを読み直すと、_ready で GameState.coins から復元されます。つまり、やり直しても小判は減りません。減らしたいなら、restart() の中で GameState.coins をステージ開始時の値に戻す処理を足します。どちらが好みかは遊んでみて決めてください。

5ステージに増やす

  • level_1.tscn をファイルシステムで右クリック →「複製」→ level_2.tscn
  • TileMapLayer の地形を描き替える
  • 敵と小判の位置を動かす
  • Camera2D の Limit → Right を、新しいステージの横幅に直す
  • Level の Next Scene に level_3.tscn を割り当てる
  • 5面目の Next Scene は空にするか、クリア画面を作る
1面目を丁寧に作る理由

2面目以降は、この複製作業の繰り返しになります。1面目に入れ忘れた仕組みは、5面分すべてに入りません。複製を始める前に、1面目が完全に遊べる状態になっているかを確認してください。

完成の目安

1ステージをスタートからゴールまで通せる。敵を倒せる。小判が集まる。やられたらやり直せる。関所に触れると次のステージへ進む。ここまでできたら、あとは面を増やすだけです。

余裕ができたら足す機能

ここから先は作らなくても完成です。上から順に、だいたい簡単な順です。「プロンプトをコピー」を押すと、このゲームの内容とコードの作りまで入った質問文がコピーされます。

やさしい

コヨーテタイムを入れる

足場から落ちた直後の数フレームだけ、まだジャンプできる。プロの2Dアクションはほぼ全部これを入れています。操作感が劇的に良くなります。

やさしい

背景を多重スクロールにする

遠くの山はゆっくり、近くの木は速く流れる。奥行きが出て、一気にそれらしくなります。

やさしい

チェックポイント

ステージの中ほどに旗を置き、やられたらそこから再開する。1面が長くなってきたら必要になります。

ふつう

小判を投げる遠距離攻撃

近接だけでなく、小判を投げて遠くの敵を倒せるようにする。飛び道具の作り方を覚えられます。

ふつう

敵の種類を増やす

飛ぶ敵、突っ込んでくる敵、踏まないと倒せない敵。いまの enemy.gd を元にすると、2種類目からは早く作れます。

ふつう

ステージクリアの演出

関所に触れたら操作を止めて、集めた小判を数え上げてから次へ。区切りがつくと達成感が出ます。

むずかしい

ボスを作る

5面の最後に、何回か攻撃しないと倒せない敵を置く。行動のパターンを持たせるので、状態管理の練習になります。

むずかしい

隠し部屋

壁の一部が抜けられて、小判がたくさんある部屋に入れる。探索の楽しみが加わります。

# player.gd

extends CharacterBody2D

signal died
signal health_changed(value: int)

const SPEED := 110.0
const JUMP  := -290.0
const MAX_HP := 3
const INVINCIBLE_TIME := 1.2

var hp := MAX_HP
var attacking := false
var invincible := false

@onready var anim: AnimationPlayer = $AnimationPlayer
@onready var sprite: Sprite2D     = $Sprite
@onready var attack_pivot: Node2D = $AttackPivot
@onready var attack_area: Area2D  = $AttackPivot/AttackArea


func _ready() -> void:
    attack_area.monitoring = false
    attack_area.body_entered.connect(_on_attack_hit)


func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity += get_gravity() * delta

    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = JUMP

    if Input.is_action_just_pressed("attack") and not attacking:
        do_attack()

    var dir := Input.get_axis("move_left", "move_right")
    if attacking:
        dir = 0.0                       # 攻撃中は足を止める
    velocity.x = dir * SPEED

    if dir != 0.0:
        sprite.flip_h = dir < 0.0
        attack_pivot.scale.x = 1.0 if dir > 0.0 else -1.0

    move_and_slide()


# ---- 攻撃 ----
func do_attack() -> void:
    attacking = true
    anim.play("attack")
    await anim.animation_finished
    attacking = false


func attack_on() -> void:               # アニメーションから呼ばれる
    attack_area.set_deferred("monitoring", true)


func attack_off() -> void:              # アニメーションから呼ばれる
    attack_area.set_deferred("monitoring", false)


func _on_attack_hit(body: Node) -> void:
    if body.has_method("take_damage"):
        body.take_damage(1)


# ---- ダメージ ----
func take_damage(amount: int) -> void:
    if invincible:
        return
    hp -= amount
    health_changed.emit(hp)
    if hp <= 0:
        died.emit()
        return

    invincible = true
    velocity.y = -160.0
    var t := create_tween().set_loops(6)
    t.tween_property(sprite, "modulate:a", 0.2, 0.1)
    t.tween_property(sprite, "modulate:a", 1.0, 0.1)
    await get_tree().create_timer(INVINCIBLE_TIME).timeout
    sprite.modulate.a = 1.0
    invincible = false

# enemy.gd

extends CharacterBody2D

const SPEED := 32.0

var dir := -1.0

@onready var floor_check: RayCast2D = $FloorCheck


func _ready() -> void:
    $TouchBox.body_entered.connect(_on_touch)


func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity += get_gravity() * delta

    if is_on_wall() or not floor_check.is_colliding():
        turn()

    velocity.x = dir * SPEED
    move_and_slide()


func turn() -> void:
    dir = -dir
    floor_check.position.x = -floor_check.position.x
    $Sprite.flip_h = dir > 0.0


func _on_touch(body: Node) -> void:
    if body.has_method("take_damage"):

level.gd 全文

# level.gd

extends Node2D

@export var next_scene: PackedScene

var coins := 0

@onready var player: CharacterBody2D = $Entities/Player
@onready var coin_label: Label = $HUD/CoinLabel


func _ready() -> void:
    coins = GameState.coins

    player.died.connect(restart)
    player.health_changed.connect(_on_health_changed)
    $KillZone.body_entered.connect(_on_kill_zone)
    $Goal.body_entered.connect(_on_goal)

    for c in get_tree().get_nodes_in_group("coin"):
        c.collected.connect(_on_coin)

    _on_health_changed(player.hp)
    update_hud()


# ---- 小判 ----
func _on_coin() -> void:
    coins += 1
    GameState.coins = coins
    update_hud()


# ---- やられた ----
func _on_kill_zone(body: Node) -> void:
    if body == player:
        restart()


func restart() -> void:
    await get_tree().create_timer(0.6).timeout
    get_tree().reload_current_scene()


# ---- ゴール ----
func _on_goal(body: Node) -> void:
    if body != player:
        return
    GameState.coins = coins
    GameState.stage += 1
    if next_scene:
        get_tree().change_scene_to_packed(next_scene)


# ---- 表示 ----
func _on_health_changed(hp: int) -> void:
    for i in $HUD/Hearts.get_child_count():
        $HUD/Hearts.get_child(i).visible = i < hp


func update_hud() -> void:
    coin_label.text = "小判 %d" % coins

詰まったときの確認手順

症状見るところ
地形をすり抜けるTileSet の物理レイヤーに当たり形を描いたか。Player の Mask に world があるか
入力アクションが無いというエラーインプットマップに4つ作ったか。名前が一致しているか
ジャンプが変な感じJUMP と Default Gravity の比率。まず重力を上げてみる
ステージ外の空白が映るCamera2D の Limit。複製したステージで直し忘れていないか
攻撃が当たらないAttackArea の Mask に enemy があるか。メソッド呼び出しトラックが動いているか
monitoring の警告が出るset_deferred を使っているか
触れた瞬間に体力が全部減る無敵時間の invincible を最初に確認しているか
敵が穴に落ちるFloorCheck の Target Position と、turn() での左右反転
小判の数が増えないグループ coin に入れたか。Mask に player があるか
次のステージへ行かないLevel の Next Scene を割り当てたか
