GDScriptの読み方 — 最低限の文法

この回のねらい：この教材のコードを「読める」ようにする。書けるようになるのは、写しているうちでよい。

文法を全部覚える必要はありません。教材に出てくる形だけ、意味が分かるようにしておきます。分からなくなったらこの回に戻ってください。

変数 — 値の入れもの

var score := 0          # 変わる値。:= は「型は右辺から察して」の意味
const SPEED := 60.0     # 変わらない値。調整用の数値はこれで持つ
var name: String = ""   # 型を自分で書く形。どちらでもよい

# から行末まではコメント（メモ）で、実行されません。60.0 のように小数点を付けると小数、付けないと整数です。

関数 — 処理のまとまり

func take_damage(amount: int) -> void:
    hp -= amount
    if hp <= 0:
        die()

読み方：「take_damage という名前の処理。整数 amount を受け取る。-> void は返す値がないという意味」。呼ぶときは take_damage(1) と書きます。

if と match — 分かれ道

if hp <= 0:
    die()
elif hp < 3:
    warn()
else:
    pass            # 何もしない

match state:        # 値によって分岐。if の連続より読みやすい
    State.MOVE:
        walk()
    State.ATTACK:
        swing()

ノードを触る記号

$ と % と @onready の詳しい使い分けは第14回でやります。ここでは読めれば十分です。

$Sprite2D.hide()                    # $ = 子ノードを名前で取る
%HealthBar.value = hp               # % = どこにいても届く特別な名前

@onready var sprite: Sprite2D = $Sprite2D
# ↑ 子ノードを変数に入れるときのお決まりの形。@onready を付けないと
#   子が用意される前に取ろうとして失敗します
