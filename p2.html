風船をふくらませて放す

新しく覚える：シーンを分けて生成・破棄する／毎フレーム少しずつ変える／sin で揺らす／ランダムを使う。

作るものを先に決める

幼児向けの、安心して繰り返せる風船遊び。

画面の下のほうに、しぼんだ風船がひとつ浮かんでいる。画面を押している間、風船はゆっくり大きくなる。指を離すと、ゆらゆらと横に揺れながら空へ上がっていき、画面の上へ消える。少し待つと、次の風船が出てくる。

風船の色は毎回変わる。空にはゆっくり雲が流れ、ときどき鳥が横切る。

割れない。記録もつかない。失敗という状態が存在しない。大きくしすぎても、上限で止まるだけです。

なぜ割らないのか

「膨らませすぎると割れる」は、大人には駆け引きになりますが、幼児には理不尽な罰になります。押していたら急に消えた、という体験は繰り返しを止めてしまいます。上限で止める設計にすると、思い切り押していい遊びになります。

この章の考え方の芯

2つだけ

1. 風船は自分のことだけを知っている。どう膨らむか、どう上がるか、いつ消えるかは、すべて風船自身が持ちます。Main がやるのは「作る」ことと「押されたと伝える」ことだけ。第13回の向きのルールを、初めて2つのシーンにまたがって使います。

2. 変化は毎フレーム少しずつ。B1では速度を扱いましたが、今回は大きさと位置を delta で少しずつ動かします。「今この瞬間どうなっているか」ではなく「1秒あたりどれだけ変わるか」を書く、という考え方に慣れてください。以降の全部の章で使います。

STEP 1

空と雲を流す

B1の背景スクロールの応用です。今回は1枚ずつ独立して流し、左へ抜けたら右から出し直します。

# main.gd

extends Node2D

const CLOUD_SPEED := 8.0     # 雲が流れる速さ（px/秒）

@onready var clouds: Node2D = $Clouds


func _process(delta: float) -> void:
    for c in clouds.get_children():
        c.position.x -= CLOUD_SPEED * delta
        if c.position.x < -80.0:
            c.position.x = 340.0
            c.position.y = randf_range(30.0, 170.0)

STEP 3

押している間ふくらむ

押している間だけ大きくなり、上限で止まります。まだ Main とはつながず、風船シーン単体で動かします。

# balloon.gd に追加

const GROW_SPEED := 1.1      # 1秒あたりどれだけ大きくなるか
const MAX_SIZE   := 3.2      # これ以上は大きくならない

var holding := false


func _process(delta: float) -> void:
    if not holding:
        return
    size = min(size + GROW_SPEED * delta, MAX_SIZE)
    scale = Vector2.ONE * size


func hold() -> void:
    holding = true


func release() -> void:
    holding = false

min() は「小さいほうを返す」関数です。size + 増加分 と MAX_SIZE を比べて小さいほうを採用するので、これだけで上限が作れます。if を書く必要はありません。

単体で確かめるために、一時的にこれを足します（あとで消します）。

# balloon.gd に一時的に追加（STEP 5 で消す）

func _input(event: InputEvent) -> void:
    if event is InputEventMouseButton:
        if event.pressed:
            hold()
        else:
            release()
ここで確認

F6で風船だけを実行し、押しっぱなしにすると大きくなる。離すと止まる。押し続けても、あるところで大きくなるのが止まる。

STEP 4

放すと、ゆらゆら上がって消える

風船に「いま何をしているか」を持たせます。B1の enum と同じ考え方です。

# balloon.gd に追加（_process を書き換える）

enum Phase { GROWING, FLYING }

const RISE_SPEED := 90.0     # 上がる速さ（px/秒）
const SWAY_WIDTH := 26.0     # 横揺れの幅（px）
const SWAY_SPEED := 2.2      # 横揺れの速さ

var phase: Phase = Phase.GROWING
var t := 0.0                 # 揺れのための経過時間
var base_x := 0.0            # 揺れの中心になる x


func _process(delta: float) -> void:
    if phase == Phase.GROWING:
        if holding:
            size = min(size + GROW_SPEED * delta, MAX_SIZE)
            scale = Vector2.ONE * size
    else:
        t += delta
        position.y -= RISE_SPEED * delta
        position.x = base_x + sin(t * SWAY_SPEED) * SWAY_WIDTH
        rotation = sin(t * SWAY_SPEED) * 0.14
        if position.y < -100.0:
            queue_free()


func release() -> void:
    if phase != Phase.GROWING:
        return
    holding = false
    phase = Phase.FLYING
    base_x = position.x
    t = 0.0
sin で揺らす

sin() は、入れた数値を増やしていくと -1 と 1 の間を往復する値を返します。だから sin(経過時間) × 幅 を x に足すと、左右に揺れます。

SWAY_SPEED を大きくすると速く揺れ、SWAY_WIDTH を大きくすると大きく揺れます。回転にも同じ値を使っているので、傾きと横移動が揃って自然に見えます。揺れの表現はほぼこれ一つで作れますので、覚えておくと後の章でも使えます。

base_x を放した瞬間に記録しているのが要点です。これがないと、揺れの中心が0（画面左端）になってしまいます。

ここで確認

F6で、押して膨らませて離すと、左右に揺れながら上へ上がっていき、画面の上で消える。下パネルの「出力」にエラーが出ていない。

STEP 5

次の風船が出てくる

ここで Main とつなぎます。風船は「放されました」と言うだけで、次を出すのは Main の仕事です。

まず、STEP 3 で一時的に足した _input を balloon.gd から削除してください。入力を受けるのは Main の役目です。

# balloon.gd に追加

signal released


# release() の最後に1行足す
    released.emit()

Main 側です。インスペクタで Balloon Scene に balloon.tscn をドラッグして割り当ててください。

# main.gd に追加

const SPAWN_X := 160.0
const SPAWN_Y := 400.0

@export var balloon_scene: PackedScene

var current: Node2D = null

@onready var balloons: Node2D = $Balloons


func _ready() -> void:
    spawn_balloon()


func spawn_balloon() -> void:
    var b := balloon_scene.instantiate()
    b.position = Vector2(SPAWN_X, SPAWN_Y)
    b.released.connect(_on_balloon_released)
    balloons.add_child(b)
    current = b


func _input(event: InputEvent) -> void:
    if current == null:
        return
    if event is InputEventMouseButton:
        if event.pressed:
            current.hold()
        else:
            current.release()


func _on_balloon_released() -> void:
    current = null
    await get_tree().create_timer(0.7).timeout
    spawn_balloon()
current が null になる意味

放した瞬間に current = null にすることで、飛んでいる風船を間違って操作しなくなります。次の風船が出るまでの0.7秒は、押しても何も起きません。「いま操作できる対象はどれか」を1つの変数で持つのは、この先も繰り返し出てくる形です。

ここで確認

F5で main.tscn を実行。押して離すと風船が飛び、少し待つと次の風船が下に現れる。これを何度でも繰り返せる。リモートツリーで Balloons を開き、風船が溜まっていないことを必ず確認してください。

STEP 6

色が毎回変わる

色は Main が決めて、生まれた風船に渡します。

# main.gd に追加

const COLORS := [
    Color("ff6b6b"), Color("ffd166"), Color("06d6a0"),
    Color("4cc9f0"), Color("c77dff"), Color("ffadad"),
]


# spawn_balloon の中に1行足す
    b.modulate = COLORS.pick_random()

modulate はそのノードと子ども全部に色をかける仕組みです。風船本体もひもも一緒に染まります。ひもだけ色を変えたくなったら、Body にだけ modulate をかける形に直します。

pick_random() は配列からひとつ選ぶ関数です。同じ色が2回続くこともありますが、幼児向けなら気にしなくて構いません。気になるなら、前回の色を覚えておいて選び直します。

ここで確認

風船が出るたびに色が変わる。ひもも一緒に色が変わっている。

STEP 7

鳥を飛ばして、仕上げる

鳥は風船と同じ作り方です。同じパターンを2回やることで、インスタンス化が身体に入ります。

bird.tscn を新規作成し、ルートを Node2D、子に小さい ColorRect を1つ置きます。

# bird.gd

extends Node2D

const SPEED := 34.0
const FLAP_SPEED := 6.0
const FLAP_HEIGHT := 5.0

var t := 0.0
var base_y := 0.0


func _ready() -> void:
    base_y = position.y


func _process(delta: float) -> void:
    t += delta
    position.x -= SPEED * delta
    position.y = base_y + sin(t * FLAP_SPEED) * FLAP_HEIGHT
    if position.x < -60.0:
        queue_free()

Main に BirdTimer（Timer、Wait Time 6秒、Autostart オン）を置き、timeout を接続します。

# main.gd に追加

@export var bird_scene: PackedScene

@onready var birds: Node2D = $Birds


func _on_bird_timer_timeout() -> void:
    var b := bird_scene.instantiate()
    b.position = Vector2(360.0, randf_range(60.0, 200.0))
    birds.add_child(b)
    $BirdTimer.wait_time = randf_range(5.0, 12.0)

最後の行で、次に鳥が出るまでの時間を毎回変えています。一定間隔だと機械的に見えるので、ゆらぎを入れます。これも覚えておくと、いろいろな場面で効きます。

幼児向けの詰め

  • ふくらむ速さを落とす。GROW_SPEED を下げると、押している時間が長くなって手応えが出ます。幼児は「押し続ける」動作自体が楽しいので、急がせないほうがよいです。
  • 次の風船までを短く。0.7秒でも長いかもしれません。0.4秒くらいまで詰めて試してください。
  • 押したら必ず何か起きる。飛んでいる最中に押しても無反応なのが気になるなら、小さい効果音だけ鳴らすようにします。
  • 音を足す。ふくらむ音を AudioStreamPlayer でループ再生し、離したら止める。これだけで体験が変わります。
  • 最後に絵を入れる。ColorRect を右クリック →「型を変更」で Sprite2D にします。
完成の目安

押す → ふくらむ → 離す → ゆらゆら上がって消える → 次が出る、が何度でも繰り返せる。色が毎回変わり、雲と鳥が流れている。風船がノードとして溜まっていない。ここまでで完成です。

やさしい

大きいほど高く、ゆっくり上がる

いまはどの大きさでも同じ速さで上がります。大きい風船はゆっくり、小さい風船はすいっと上がるようにすると、膨らませる意味が生まれます。

やさしい

ふくらむ音を鳴らす

押している間だけ音が鳴り、大きくなるほど音が高くなる。離すと止まる。幼児向けでは音の効果がとても大きいです。

やさしい

ひもを揺らす

いまのひもは棒のままです。風船の揺れに少し遅れてついてくるようにすると、生き物っぽくなります。

ふつう

離した瞬間にキラッと光る

手を離した合図をはっきりさせる演出です。一瞬だけ白く光らせて戻すだけでも、離したことがよく伝わります。

ふつう

風船を2つ同時に出す

いまは1つずつです。同時に2つ出して、押した位置に近いほうが膨らむようにすると、遊び方が広がります。

ふつう

空が時間で変わる

遊んでいるうちに、朝から昼、夕方へと空の色がゆっくり移り変わる。雲の色も一緒に変えると効果が出ます。

むずかしい

風船が雲の後ろを通る

上がっていく風船が、雲にさしかかると少し隠れる。前後関係の表現なので、第17回の描画順の実践になります。

むずかしい

画面をなぞると風が吹く

指でなぞった方向に、飛んでいる風船が少し押される。触った位置と動きを使うので、入力の扱いが一段深くなります。

むずかしい

動物の形の風船

ふつうの風船に混じって、ときどき動物の形のものが出る。出現の確率を持たせるので、ランダムの扱いが一段深くなります。
