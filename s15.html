Autoload — 全体で1つだけのもの

この回のねらい：便利すぎる仕組みを、使いすぎずに使う。

Autoloadは、ゲーム起動時に自動で読み込まれ、シーンを切り替えても消えないノードです。プロジェクト設定 → Autoload でスクリプトかシーンを登録すると、どこからでも名前で呼べます。

# res://autoload/game_state.gd
extends Node

var score: int = 0
var current_stage: int = 1

signal score_changed(value: int)

func add_score(n: int) -> void:
    score += n
    score_changed.emit(score)

登録名を GameState にすれば、どのスクリプトからでも GameState.add_score(10) と書けます。

入れていいもの

  • セーブデータ、スコア、進行状況
  • BGMプレイヤー（シーンを跨いで鳴らし続けたい）
  • シーン切り替えの管理・画面転換の演出
  • 設定（音量、キー配置）
使いすぎに注意

どこからでも触れるということは、どこで壊れたか分からなくなるということでもあります。「全シーンで共有する状態」だけに絞ってください。プレイヤーの体力のように1つのシーンに属するものは、そのシーンに持たせます。

やってみる

game_state.gd を作り、Autoloadに登録する。別のスクリプトから GameState.score = 5 と書いて print できることを確認する。
