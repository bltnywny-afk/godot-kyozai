音を整える — オーディオバス

この回のねらい：BGMと効果音を別々に管理し、音量を設定できるようにする。

音を鳴らすノードは第10回で扱いました。ここでは全体の音量をどう管理するかです。

バスを分ける

下パネルの「オーディオ」タブを開くと、Master というバスが1本あります。ここに BGM と SE を追加します。

  • 「バスを追加」を2回押し、名前を BGM と SE にする
  • それぞれの出力先を Master にする
  • AudioStreamPlayer のインスペクタで、Bus を BGM か SE に設定する

これで、BGMだけ音量を下げる・効果音だけ消すといった操作ができるようになります。

設定画面から音量を変える

func set_bgm_volume(value: float) -> void:
    # value は 0.0〜1.0
    var bus := AudioServer.get_bus_index("BGM")
    AudioServer.set_bus_volume_db(bus, linear_to_db(value))
音量は dB で持っている

Godotの音量はデシベルです。0が原寸、マイナスで小さくなり、-80 でほぼ無音。スライダーの 0〜1 とは尺度が違うので、linear_to_db() で変換します。これを知らないと「スライダーを半分にしたのに、ほとんど小さくならない」ことになります。

同じ音を重ねて鳴らす

コインを連続で取ったとき、音が途切れて聞こえることがあります。AudioStreamPlayer の Max Polyphony を 4〜8 に上げると、重ねて鳴らせるようになります。

効果音を用意するときの実際

  • フリー素材を使うなら、商用利用とクレジット表記の条件を確認する
  • 自分で作るなら jsfxr のようなレトロ効果音生成ツールが手軽
  • 音量は素材ごとにバラバラなので、ゲーム内で揃える（AudioStreamPlayer の Volume dB）
やってみる

BGM と SE のバスを作り、既存の AudioStreamPlayer を振り分ける。オーディオタブでBGMのつまみだけ下げて、効果音の音量が変わらないことを確認する。
