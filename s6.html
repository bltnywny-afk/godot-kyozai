Node / Node2D / Control の3系統

この回のねらい：数百あるノードを3つに分類して見られるようにする。

ノードの一覧を初めて開くと数が多くて絶望しますが、2Dゲームで使うものは大きく3系統です。

系統持っているもの使いどころ
Node何も持たないただのまとめ役、ロジックだけの入れ物
Node2D位置・回転・拡大ゲーム世界に置くものすべて
Control矩形とアンカーUI。画面サイズに合わせて伸縮する

見分け方は簡単で、ワールド座標で置きたいならNode2D系、画面の隅に貼り付けたいならControl系です。体力バーを敵の頭上に出すならNode2D系、画面左上に固定するならControl系。

まとめ役としてのNode

位置を持たないので、整理のためだけに使えます。

Level
├─ Terrain     (Node2D)
├─ Enemies     (Node)   ← 敵をまとめるだけ
│  ├─ Enemy
│  └─ Enemy
└─ Items       (Node)

こうしておくと、敵を全部消したいときに Enemies の子を消すだけで済みます。

やってみる

ノード追加ダイアログを開き、検索欄に 2D と入れる。出てくるノードの名前を眺めるだけでよい。
